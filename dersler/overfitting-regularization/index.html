Aşırı Öğrenme ve Düzenlileştirme

📚 M5 · ML/DL Serisi⏱ ~25 dakika
Bu derste öğrenecekleriniz: Overfitting/underfitting ayrımı, dropout, L1/L2, erken durdurma ve veri artırma. "Model ezberliyor" sorununu tespit etmek ve çözmek.

Underfitting vs Doğru Öğrenme vs Overfitting

Underfitting
Model çok basit
Eğitim+Test'te kötü
(model görmemiş gibi)
→
İyi Öğrenme
Hem eğitim hem test
iyi — model genelleme yapıyor
→
Overfitting
Eğitimde mükemmel
Test'te kötü (ezberleme)
💡 Analoji

Sınav öncesi çalışan öğrenci gibi düşünün:
Underfitting: Hiç çalışmamış — ne soru çözebilir ne anlar.
Doğru öğrenme: Konuyu kavramış — her türlü soruya cevap verir.
Overfitting: Sadece örnek soruların cevaplarını ezberlemiş — görmediği soruda tökezler.

Overfitting'i Tespit Etmek

# Overfitting sinyali: train acc ↑ val acc ↓ (gap açılıyor)
# Eğitim eğrilerinde bu "V" oluşumu:

# Epoch    Train Loss   Val Loss
#   1        0.9         0.85
#   5        0.4         0.50
#  10        0.1         0.62  ← Burada val loss artıyor! OVERFIT!
#  15        0.02        0.78  ← Durmak gerekirdi (erken durdurma noktası)

Çözüm 1: Dropout — Rastgele Nöronları Kapat

Dropout, her eğitim adımında nöronların bir kısmını rastgele kapatır. Model, tek bir nörona "güvenemez" hale gelir; daha sağlam, genelleştirilebilir özellikler öğrenir. 

import torch.nn as nn

# nn.Sequential yada nn.Module içinde:
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),   # Her adımda %50 nöron kapat
    nn.Linear(256, 10)
)

# ⚠️ model.eval() çağrıldığında dropout otomatik devre dışı kalır!
💡 Dropout Analojisi

Sadece en iyi oyuncusuna bağımlı bir basketbol takımı, o oyuncu sakatlanınca çöker. Dropout, her antrenmanda rastgele oyuncuları yedek bırakarak takımı "herkesle oynayabilen" hale getirir — daha sağlam, daha dengeli.

Çözüm 2: L1 ve L2 Regularization

# Kayıp = orijinal kayıp + ceza_terimi

# L2 (Ridge) — Büyük ağırlıkları cezalandır.
# Amaç: ağırlıkları küçük tutmak (smooth model)
kayip = orijinal_kayip + lambda_ * (agirliklar ** 2).sum()

# L1 (Lasso) — Toplam büyüklüğü cezalandır.
# Ağırıkları sıfıra itebilir → özellik seçimi yapabilir
kayip = orijinal_kayip + lambda_ * (agirliklar.abs()).sum()

# PyTorch'ta weight_decay parametresiyle L2 uygulanır:
optimizer = torch.optim.Adam(model.parameters(), lr=0.001, weight_decay=1e-4)

Çözüm 3: Erken Durdurma (Early Stopping)

en_iyi_val_kayip = float("inf")
sabir_sayaci = 0
SABIR_LIMITI = 5   # 5 epoch iyileşmezse dur

for epoch in range(100):
    # ... eğitim adımları ...
    val_kayip = degerlendir(model, val_loader)

    if val_kayip < en_iyi_val_kayip:
        en_iyi_val_kayip = val_kayip
        torch.save(model.state_dict(), "en_iyi_model.pt")  # En iyi checkpoint
        sabir_sayaci = 0
    else:
        sabir_sayaci += 1
        if sabir_sayaci >= SABIR_LIMITI:
            print(f"Erken durma: Epoch {epoch}")
            break

# İşlem bitince en iyi checkpoint'i yükle
model.load_state_dict(torch.load("en_iyi_model.pt"))

Çözüm 4: Veri Artırma (Data Augmentation)

Görüntüleri döndür, yansıt, kırp — model, nesnenin sadece bir pozisyonunu değil her halini görsün. Veri artırmak, modelin "ezberlemesi" gereken doğru cevap setini genişletir ve genellemeyi artırır. 

from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),          # 180° yansıt (%50 şans)
    transforms.RandomRotation(15),               # ±15° döndür
    transforms.ColorJitter(brightness=0.2),      # Parlaklık değiştir
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),  # Kırp
    transforms.ToTensor(),
])

# Test verisine augmentation YAPILMAZ — model sadece eğitimde "daha çok görür"
