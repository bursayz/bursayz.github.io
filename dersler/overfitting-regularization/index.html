Aşırı Öğrenme ve Düzenlileştirme

📚 M5 · ML/DL Serisi⏱ ~25 dakika
Bu derste öğrenecekleriniz: Overfitting/underfitting ayrımı, dropout, L1/L2, erken durdurma ve veri artırma. "Model ezberliyor" sorununu tespit etmek ve çözmek. (Düzenlileştirme, İngilizce karşılığı "regularization" nedeniyle bazı kaynaklarda "regülarizasyon" olarak da geçer.)

Underfitting vs Doğru Öğrenme vs Overfitting

UNDERFITTING
Model çok basit
Eğitim+Test'te kötü
(model veriyi yakalayamıyor)
→
İYİ ÖĞRENME
Hem eğitim hem test
iyi — model genelleme yapıyor
→
OVERFITTING
Eğitimde mükemmel
Test'te kötü (ezberleme)
💡 ANALOJİ

Sınav öncesi çalışan öğrenci gibi düşünün:
Underfitting: Hiç çalışmamış — ne soru çözebilir ne anlar.
Doğru öğrenme: Konuyu kavramış — her türlü soruya cevap verir.
Overfitting: Sadece örnek soruların cevaplarını ezberlemiş — görmediği soruda tökezler.

Overfitting'i Tespit Etmek

# Overfitting sinyali: train loss ↓ devam ederken val loss ↑ döner (gap açılır)
# Eğitim eğrilerinde val loss'ta bu "U" oluşumu:

# Epoch    Train Loss   Val Loss
#   1        0.9         0.85
#   5        0.4         0.50  ← val loss minimuma yaklaşıyor
#   7        0.25        0.47  ← minimum civarı: durmak için ideal nokta
#  10        0.1         0.62  ← Burada val loss artıyor! OVERFIT!
#  15        0.02        0.78  ← Çok geç — model ezberlemiş

Çözüm 1: Dropout — Rastgele Nöronları Kapat

Dropout, her eğitim adımında nöronların bir kısmını rastgele kapatır. Model, tek bir nörona "güvenemez" hale gelir; daha sağlam, genelleştirilebilir özellikler öğrenir. 

import torch.nn as nn

# nn.Sequential ya da nn.Module içinde:
model = nn.Sequential(
    nn.Linear(784, 512),
    nn.ReLU(),
    nn.Dropout(p=0.3),   # Her adımda nöronların %30'unu kapat
    nn.Linear(512, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),   # Son katmana yakın daha yüksek oran yaygındır
    nn.Linear(256, 10)
)

# ⚠️ model.eval() çağrıldığında dropout otomatik devre dışı kalır!
# ⚠️ Değerlendirme bitince eğitime dönmek için model.train() çağırmayı unutmayın.
# Not: PyTorch eğitimde kalan nöronları 1/(1-p) ile ölçekler (inverted dropout),
# böylece test anında ekstra ölçekleme gerekmez.
💡 DROPOUT ANALOJİSİ

Sadece en iyi oyuncusuna bağımlı bir basketbol takımı, o oyuncu sakatlanınca çöker. Dropout, her antrenmanda rastgele oyuncuları yedek bırakarak takımı "herkesle oynayabilen" hale getirir — daha sağlam, daha dengeli.

Çözüm 2: L1 ve L2 Regularization

# Kayıp = orijinal kayıp + ceza_terimi
# agirliklar: modelin tüm ağırlık parametreleri birleştirilmiş tek bir tensör gibi düşünün

# L2 (Ridge) — Büyük ağırlıkları cezalandır.
# Amaç: ağırlıkları küçük tutmak (smooth model)
kayip = orijinal_kayip + lambda_ * (agirliklar ** 2).sum()

# L1 (Lasso) — Ağırlıkların mutlak değerlerinin toplamını cezalandır.
# Ağırlıkları sıfıra itebilir → özellik seçimi yapabilir
kayip = orijinal_kayip + lambda_ * (agirliklar.abs()).sum()

# lambda_ (ceza katsayısı) bir hiperparametredir; ağırlık çapraz doğrulama ile seçilir
# (örn. 1e-5 ile 1e-2 arasında logaritmik tarama).

# PyTorch'ta SGD'de weight_decay parametresi L2 cezasına eşdeğerdir:
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=1e-4)

# ⚠️ Adam'da weight_decay gerçek L2 cezası gibi davranmaz — ceza gradyana eklenir
# ve adaptif ölçeklemeden geçer (Loshchilov & Hutter, 2019). Adam için doğrusu AdamW'dir:
optimizer = torch.optim.AdamW(model.parameters(), lr=0.001, weight_decay=1e-4)

Çözüm 3: Erken Durdurma (Early Stopping)

en_iyi_val_kayip = float("inf")
sabir_sayaci = 0
SABIR_LIMITI = 5   # 5 epoch iyileşmezse dur

for epoch in range(100):
    # ... eğitim adımları ...
    val_kayip = degerlendir(model, val_loader)

    if val_kayip < en_iyi_val_kayip:
        en_iyi_val_kayip = val_kayip
        torch.save(model.state_dict(), "en_iyi_model.pt")  # En iyi checkpoint
        sabir_sayaci = 0
    else:
        sabir_sayaci += 1
        if sabir_sayaci >= SABIR_LIMITI:
            print(f"Erken durma: Epoch {epoch}")
            break

# İşlem bitince en iyi checkpoint'i yükle
model.load_state_dict(torch.load("en_iyi_model.pt"))

Çözüm 4: Veri Artırma (Data Augmentation)

Görüntüleri döndür, yansıt, kırp — model, nesnenin sadece bir pozisyonunu değil her halini görsün. Veri artırma, eğitim dağılımını çeşitlendirerek modelin ezberlemesini zorlaştırır ve genellemeyi artırır. 

from torchvision import transforms

train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),           # Yatay aynalama (%50 olasılık)
    transforms.RandomRotation(15),               # ±15° döndür
    transforms.ColorJitter(brightness=0.2),      # Parlaklık değiştir
    transforms.RandomResizedCrop(224, scale=(0.8, 1.0)),  # Kırp ve 224x224'e boyutla
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],      # ImageNet ön eğitimli
                         std=[0.229, 0.224, 0.225]),      # modeller için gerekli
])

# Doğrulama/test için rastgele dönüşümler YAPILMAZ; ama tahmin öncesi deterministik
# ön işleme yine gerekir (Resize + CenterCrop + Normalize):
val_transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std=[0.229, 0.224, 0.225]),
])
# Not: Bazı ileri senaryolarda test anında da augmentation uygulanır
# (test-time augmentation / TTA) ve tahminler ortalanır.
