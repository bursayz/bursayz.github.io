Edge ve Mobil AI

📚 U4 · Uzman Serisi⏱ ~30 dakika
Bu derste öğrenecekleriniz: Modelleri buluttan cihaza getirmek: ONNX dönüştürme, TensorFlow Lite, CoreML, tarayıcıda WebNN/WebGPU ve edge cihazların kısıtları (RAM, pil, NPU).

Neden Cihazda (Edge) Çalıştırmak?

  • Gizlilik: Veri cihazdan çıkmaz — sağlık ve finans uygulamalarında kritik.
  • Gecikme: Ağ gidiş-dönüşü (50-500ms) yerine yerel hesap (5-20ms). Gerçek zamanlı AR/otonom sürüş için zorunlu.
  • Çevrimdışı çalışma: Uçak modunda bile çalışan uygulamalar.
  • Maliyet: Bulut inference ücreti yerine kullanıcının cihazının gücünü kullanmak.

Format Zinciri: PyTorch → ONNX → Cihaz

import torch

# 1. PyTorch modelini ONNX'a aktar
torch.onnx.export(
    model, torch.randn(1, 3, 224, 224), "model.onnx",
    opset_version=17, dynamic_axes={"input": {0: "batch"}}
)

# 2. ONNX → TensorFlow Lite (onnx-tf köprüsüyle) veya doğrudan:
#    onnxruntime ile CPU/NPU/GPU üzerinde her yerde çalışır
import onnxruntime as ort
sess = ort.InferenceSession("model.onnx", providers=["CPUExecutionProvider"])

Tarayıcıda AI: Sunucusuz Demo

// Tarayıcıda transformers.js ile metin sınıflandırma — hiç sunucu yok!
import { pipeline } from "https://cdn.jsdelivr.net/npm/@xenova/transformers";

const siniflandirici = await pipeline(
    "sentiment-analysis",
    "Xenova/distilbert-base-uncased-finetuned-sst-2-english"
    // İlk çalıştırmada model (~65MB) indirilir, sonra tarayıcı cache'ler
);

const sonuc = await siniflandirici("Bu eğitim platformu harika!");
// [{ label: "POSITIVE", score: 0.998 }] — hesaplama kullanıcının cihazında
💡 ANALOJİ

Bulut AI restoranda yemek yemek gibidir: profesyonel ama gidip gelmeniz gerekir. Edge AI evde yemek yapmaktır: malzeme (model) bir kere alınır, sonra her şey yerinde. Quantization (U1) ve distillation (U3) bu dersin anahtarlarıdır — modele "diyet" yaptırmadan telefona sığmaz.

Edge Kısıtları ve Stratejiler

  • RAM: Telefon uygulaması 100-500 MB model bütçesi (INT4 quantization şart).
  • Pil: Sürekli NPU kullanımı ısınır → batch küçük tut, ihtiyaç anında çalıştır.
  • Belirsiz donanım: Kullanıcının cihazı 5 yaşında olabilir → graceful degradation (küçük model fall-back'i).
  • Güncelleme: Model dosyası uygulama paketine gömülür — OTA (over-the-air) model indirme stratejisi planlayın.

İnteraktif: Cihaz-Hız-Bellek Haritası
