Transfer Learning ve İnce Ayar

📚 G3 · Görüntü Serisi⏱ ~30 dakika
Bu derste öğrenecekleriniz: Milyonlarca resimle eğitilmiş hazır modelleri kendi az verinize nasıl adapte edersiniz? Özellik çıkarımı vs ince ayar, freeze/unfreeze stratejileri ve ne zaman hangisini kullanmalısınız.

Sıfırdan Eğitim Çoğu Zaman Gereksiz

2024'te bir kedi-köpek sınıflandırıcısı yapmak için ImageNet'in (~14 milyon resim, yüzlerce GPU saati) yeniden eğitilmesine gerek yok. Transfer learning ile hazır bir "görme beyni"ni alıp kendi görevinize adapte edersiniz.

💡 Analoji

Tıp öğrencisi önce genel anatomi öğrenir (ImageNet — evrensel görme bilgisi), sonra uzmanlık seçer (sizin göreviniz — kardiyoloji gibi). Kimse kardiyolog olmak için anatomiyi yeniden keşfetmez. İlk katmanlar kenar/doku görmeyi öğrenmiş — bu bilgi kedi ile araba arasında paylaşılır.

İki Temel Strateji

1. Özellik Çıkarımı (Feature Extraction / Freeze)

import torch
import torch.nn as nn
from torchvision import models

model = models.resnet18(weights="IMAGENET1K_V1")

# Tüm backbone'u dondur — ağırlıklar değişmez
for p in model.parameters():
    p.requires_grad = False

# Sadece son katmanı değiştir (1000 ImageNet sınıfı → 2 sınıfımız)
model.fc = nn.Linear(model.fc.in_features, 2)

# Eğitimde sadece fc'nin ~1024 parametresi eğitilir
print(len([p for p in model.parameters() if p.requires_grad]))  # 2

✅ Avantajlar: az veri (yüzlerce örnek yeterli), hızlı, overfitting riski düşük.
❌ Dezavantaj: modelin "gördüğü" özellikler sizin görevinize tam uymayabilir.

2. İnce Ayar (Fine-Tuning / Unfreeze)

# Tüm katmanlar eğitilebilir, ama farklı LR ile
for p in model.parameters():
    p.requires_grad = True

# İlk katmanlara küçük LR (ImageNet bilgisini koru),
# son katmanlara büyük LR (yeni görevi öğren)
optimizer = torch.optim.Adam([
    {"params": model.layer1.parameters(), "lr": 1e-5},   # Genel özellikler
    {"params": model.layer4.parameters(), "lr": 1e-4},   # Üst seviye
    {"params": model.fc.parameters(),     "lr": 1e-3},   # Yeni başlık
], lr=1e-3)

✅ Avantajlar: en iyi performans, göreve tam adaptasyon.
❌ Dezavantaj: daha fazla veri gerekir (binlerce), overfitting riski, daha yavaş.

Strateji Seçim Kılavuzu

Pratik: Tam Kedi-Köpek İnce Ayar

import torch
from torchvision import models, transforms, datasets
from torch.utils.data import DataLoader

# Veri
tf = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])  # ImageNet istatistikleri!
])
train = datasets.ImageFolder("veri/train", transform=tf)   # klasor/kedi/, klasor/kopek/
loader = DataLoader(train, batch_size=32, shuffle=True)

model = models.resnet18(weights="IMAGENET1K_V1")
model.fc = nn.Linear(model.fc.in_features, 2)

device = "cuda" if torch.cuda.is_available() else "cpu"
model = model.to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-4)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(10):
    model.train()
    for X, y in loader:
        X, y = X.to(device), y.to(device)
        optimizer.zero_grad()
        loss = loss_fn(model(X), y)
        loss.backward()
        optimizer.step()
torch.save(model.state_dict(), "kedi_kopek.pt")
⚠️ ImageNet Normalizasyonu

Önceden eğitilmiş model, [0.485, 0.456, 0.406] ortalama ve [0.229, 0.224, 0.225] std ile eğitilmiştir. Kendi verinizi mutlaka aynı değerlerle normalize edin — yoksa modelin "beklediği girdi dağılımı" bozulur ve performans çökürür.
