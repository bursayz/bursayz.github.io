LoRA ve QLoRA

📚 L8 · LLM Serisi⏱ ~40 dakika
Bu derste öğrenecekleriniz: Neden tüm ağırlıkları eğitmek gereksiz? Düşük rank ayrışımı (A×B), LoRA'nın matematiği, QLoRA ile 4-bit quantization birleşimi ve tek bir tüketici GPU'sunda 7B model eğitimi. Modern YZ mühendisliğinin en değerli becerisi.

Problem: Tam Fine-Tuning Çok Pahalı

7 milyar parametreli bir modelin tüm ağırlıklarını eğitmek isterseniz, sadece ağırlıklar 14 GB (FP16) yer tutar — bir de gradyanlar ve optimizer durumları eklenir: gerçek gereksinim ~80-100 GB VRAM. Bu, veri merkezi GPU'su demektir. LoRA bu sorunu kökten çözer ve oyunun kurallarını değiştirir.

LoRA'nın Temel İçgörüsü

Araştırmacılar şunu fark etti: fine-tuning sırasında ağırlık matrislerindeki değişim (ΔW) aslında "düşük ranklı"dır — yani devasa matrisi güncellemenin yerine, bu değişimi iki küçük matrisin çarpımıyla ifade edebilirsiniz: 

# Normal: W (4096 × 4096) = 16.8 milyon parametre, hepsini eğitmek gerekiyor
# LoRA: ΔW = A × B
#   A: (4096 × r)   — r = 16 olsun → 65.536 parametre
#   B: (r × 4096)   — r = 16 olsun → 65.536 parametre
# Toplam: ~131K parametre — 16.8M yerine! %99.2 daha az!

# İleri geçişte:
# Eski:  y = W @ x
# LoRA:  y = W @ x + (B @ A) @ x     # W donmuş, sadece A ve B eğitilir
💡 Analoji

Tam fine-tuning evi yıkıp yeniden inşa etmektir. LoRA ise sadece oda boyamaktır: evin iskeleti (W) aynen durur, üzerine ince bir katman (A×B) sürersiniz. Sonuçta odayı tamamen dönüştürürsünüz ama taşınmazın değerine dokunmamış olursunuz. Bir gün rengi beğenmezseniz, boyayı siler eski eve dönersiniz (adaptörü çıkarmak yeterli).

LoRA Hiperparametreleri

  • rank (r): Düşük boyutun genişliği. 8-64 arası tipik. Küçük r = daha az parametre, daha az ifade gücü. Karmaşık görevlerde 32-64 deneyin.
  • alpha (α): Ölçekleme faktörü; effective LR α/r oranıyla belirlenir. α = 2r başlangıç için iyidir.
  • target_modules: Hangi katmanlara LoRA ekleneceği. Tipik: attention'daki q, k, v, o projeksiyonları (bazen FFN'e de eklenir).

QLoRA: Dondurucuya İnanılmaz Sıkıştırma

# QLoRA = LoRA + NF4 quantization
# Temel model ağırlıkları 4-bit'e sıkıştırılır (NormalFloat4 — LLM ağırlık
# dağılımına uygun), LoRA adaptörleri bf16'da eğitilir.
# Sonuç: 7B modeli RTX 3060 (12GB) ile eğitebilirsiniz!

from transformers import AutoModelForCausalLM, BitsAndBytesConfig
import torch

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",          # NormalFloat4
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,     # Double quantization: +0.4 bit/param tasarruf
)

model = AutoModelForCausalLM.from_pretrained(
    "Qwen/Qwen2.5-7B-Instruct",
    quantization_config=bnb_config,
    device_map="auto"
)

from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training

model = prepare_model_for_kbit_training(model)  # Gradyan checkpointing vs.
lora_config = LoraConfig(
    r=16, lora_alpha=32,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# "trainable params: 33,554,432 || all params: 7,649,480,704 || trainable: 0.44%"
