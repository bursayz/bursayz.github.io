Düzenleme Modeli İnce Ayarı

📚 G8 · Görüntü Serisi⏱ ~30 dakika
Bu derste öğrenecekleriniz: DreamBooth ile bir kavramı (kişi, nesne, stil) Stable Diffusion'a nasıl öğretirsiniz, LoRA ile adaptör eğitme ve veri gereksinimleri. Öznel görsel kimlik oluşturmanın teknik temeli.

DreamBooth: "Benim Kedim" Dersi

Stable Diffusion bilgisi geneldir: "kedi" yazarsanız genel bir kedi çıkar. DreamBooth 3-5 fotoğrafla kendi nesnenizi/kişinizi öğretir. 

# DreamBooth ile LoRA eğitimi (diffusers ile)
# Veri: 3-20 fotoğraf, her biri konuyu farklı açıdan göstermeli
# Önemli: tek ve tutarlı bir "tetikleyici token" kullanın: "sks kedi" (nadir kelime)

from diffusers import StableDiffusionPipeline
import torch

# Temel mod + LoRA adaptörü yükle
boru = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
).to("cuda")
boru.load_lora_weights("./kedim_lora.safetensors")

# Artık tetikleyici kelime kendi nesnenizi çağırır:
sonuc = boru("sks kedim Sahilde güneşleniyor, fotoğraf gerçekçi").images[0]
💡 Analoji

SD genel bir ressamdır: "kedi yap" derseniz herhangi bir kedi yapar. DreamBooth, ressama sizin kedinizin 20 fotoğrafını gösterir ve "bu özel noktayı not et" dersiniz. Artık "sks kedim" dediğinizde sizin kedinizi çizer. LoRA bunu 16 MB'lık adaptör dosyasıyla yapar — tüm SD modeli (2+ GB) değişmez.

Neden Tetikleyici Token (Trigger Word)?

"sks" gibi nadir bir token seçmek, modelin var olan "kedi" bilgisini ezmeden sizin nesnesi için yeni bir "kimlik yuvası" oluşturur. Gerçek kelime kullanırsanız (örn. "kedi") modelin genel kedi bilgisi bozulabilir (overfitting riski).

LoRA Uygulaması (LLM'den Farkı)

# Diffusion'da LoRA hedefi: UNet'in attention katmanları (to_q, to_k, to_v)
# ve cross-attention Q projeksiyonları (metin bağlantısı)
from peft import LoraConfig

lora_config = LoraConfig(
    r=8,                      # Küçük rank yeterli — stil/konsept basit
    lora_alpha=16,
    target_modules=["to_q", "to_k", "to_v", "to_out.0"],
    lora_dropout=0.05
)
# Eğitim verisi: 3-20 fotoğraf + aynı caption: "sks kedi fotoğrafı"
# Overfitting koruyucu: class images (diğer kedilerin resimleri) eklenir

Veri Rehberi: Kaç Resim?

  • Nesne (kedi, araba modeli): 5-10 fotoğraf, farklı açılar, farklı arka planlar
  • Yüz (kişi): 10-20 fotoğraf, farklı ifadeler/ışıklar
  • Stil (örn. Van Gogh): 20-50 eser, aynı stil
  • Kural: Arka planda çeşitlilik sağlayın, konu tutarlı kalsın. Aynı arka plan = model onu da öğrenir.
