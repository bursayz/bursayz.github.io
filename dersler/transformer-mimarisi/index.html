Attention Yetmez — Bir Blok Lazım

Önceki derste attention'ın kelimelerin birbirine bakmasını sağladığını gördük. Ama tek attention katmanı bir dil modeli yapmaz. Transformer bloğu, attention'ı üç kritik bileşenle tamamlar: residual bağlantı, layer normalization ve feed-forward ağ.

Residual Bağlantı: Bilgi Otoyolu

# Residual: çıktı = katman(x) + x
# Bilgi katmanı "atlayarak" doğrudan ileri akar

cikis = x + self.attention(x)   # Attention ne eklediyse eklesin,
                                 # ama orijinal x kaybolmasın
💡 ANALOJİ

Residual bağlantı, bir belgeyi düzenlerken orijinal metni silmemek gibidir. Her düzenleme katmanı (attention, feed-forward) belgeye ekleme yapar ama orijinali korur. Orijinali silseniz 100 katman sonra başlangıçtaki cümle kaybolurdu. Gradyanlar da bu "otoyol"dan akarak ilk katmanlara sağlıklı ulaşır.

Layer Normalization: Değerleri Dengede Tut

# Her tokenın vektörünü: ortalama=0, varyans=1 yap
def layer_norm(x, eps=1e-5):
    ort = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    return (x - ort) / (var + eps).sqrt()

# Neden? Değerler katman katman büyürse/küçülürse eğitim kararsızlaşır.
# LayerNorm her katman girişini "aynı ölçeğe" çeker.

Feed-Forward Ağı: Her Tokenın Kişisel İşlemcisi

class FeedForward(nn.Module):
    def __init__(self, embed_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(embed_dim, 4 * embed_dim),  # Genişlet: 768 → 3072
            nn.GELU(),                            # Aktivasyon
            nn.Linear(4 * embed_dim, embed_dim),  # Daralt: 3072 → 768
        )
    def forward(self, x):
        return self.net(x)

# Attention: tokenlar arası iletişim kurar ("sosyalleşme")
# Feed-forward: her token bu bilgiyi kendi içinde işler ("derin düşünme")

Tam Transformer Bloğu — PyTorch ile

import torch
import torch.nn as nn

class TransformerBlok(nn.Module):
    def __init__(self, embed_dim, n_bas):
        super().__init__()
        self.ln1 = nn.LayerNorm(embed_dim)
        self.att = MultiHeadAttention(embed_dim, n_bas)  # L3 dersindeki
        self.ln2 = nn.LayerNorm(embed_dim)
        self.ffn = FeedForward(embed_dim)

    def forward(self, x):
        # Pre-norm mimarisi (modern GPT'ler böyle kullanır):
        x = x + self.att(self.ln1(x))   # Attention + residual
        x = x + self.ffn(self.ln2(x))   # Feed-forward + residual
        return x

# GPT-2 small: bu bloktan 12 tane üst üste!
class GPT(nn.Module):
    def __init__(self, vocab, embed_dim, n_bas, n_blok, max_len):
        super().__init__()
        self.token_emb = nn.Embedding(vocab, embed_dim)
        self.pos_emb = nn.Embedding(max_len, embed_dim)
        self.bloklar = nn.ModuleList([TransformerBlok(embed_dim, n_bas) for _ in range(n_blok)])
        self.ln_final = nn.LayerNorm(embed_dim)
        self.kafa = nn.Linear(embed_dim, vocab, bias=False)  # Çıktı: her kelime için skor

    def forward(self, token_idler):
        T = token_idler.shape[1]
        x = self.token_emb(token_idler) + self.pos_emb(torch.arange(T))
        for blok in self.bloklar:
            x = blok(x)
        x = self.ln_final(x)
        return self.kafa(x)   # (batch, T, vocab) → her pozisyon için kelime skorları

Encoder vs Decoder Farkı

  • Encoder (BERT tarzı): Maskeleme yok — her kelime her yöne bakabilir. Anlama görevlerinde iyi (sınıflandırma, NER).
  • Decoder (GPT tarzı): Nedensel maske — sadece geçmişe bakar. Metin üretimi için tasarlandı.
  • Encoder-Decoder (T5, orijinal Transformer): Çeviri gibi giriş-çıkış dönüşümlerinde kullanılır.
⚠️ BOYUTLARIN BÜYÜKLÜĞÜ

GPT-2 small: 12 blok, 768 boyut, 117M parametre. GPT-3: 96 blok, 12.288 boyut, 175M parametre. Mimari tamamen aynı — sadece ölçek değişir. Bir sonraki derste kendi mini-GPT'nizi eğiteceksiniz!
