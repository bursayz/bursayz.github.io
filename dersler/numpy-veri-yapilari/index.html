NumPy ve Veri Yapıları

📚 T4 · Temel Serisi ⏱ ~25 dakika
Bu derste öğrenecekleriniz: Neden Python listeleri yetmez? NumPy array kavramı, shape (şekil), indeksleme, broadcasting, temel istatistik işlemleri. Bu, her YZ modelinin veriyi okuma dilidir.

Neden Python Listesi Yetmez?

Python'un kendi listesi günlük işler için harikadır ama yapay zekada milyonlarca sayıyla çalışırsınız. Python listesi bu iş için çok yavaştır — her eleman ayrı bir nesne, bellekte rastgele dağılmış, ve her işlemde Python yorumlayıcısı tek tek dolaşmak zorunda. 

# Python listesi ile 1 milyon sayıyı 2 ile çarpmak — YAVAŞ
import time

liste = list(range(1_000_000))
t0 = time.time()
[b * 2 for b in liste]
print("Python listesi:", time.time() - t0, "saniye")

# NumPy ile aynı iş — HIZLI
import numpy as np
dizi = np.arange(1_000_000)
t0 = time.time()
dizi * 2
print("NumPy:", time.time() - t0, "saniye")   # Genellikle 10-100x daha hızlı
💡 Analoji

Python listesi, her ürünü ayrı raftan tek tek aldığınız bir market gibi. NumPy ise bir forklift: paleti olduğu gibi kaldırır, tek hamlede taşır. Aynı işi yapar ama "yap şekli" farklıdır — NumPy işlemi C dilinde, tek seferde yapar.

Array: NumPy'nın Temel Veri Yapısı

import numpy as np

# 1D array (vektör): tek bir satır
vektor = np.array([1, 2, 3, 4, 5])

# 2D array (matris): tablo
matris = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

# 3D array (küp): resim — yükseklik × genişlik × renk kanalı
resim = np.zeros((224, 224, 3))  # 224×224 piksel, RGB

Shape: Verinin Ölçüleri

print(vektor.shape)    # (5,)     → 1 boyutlu, 5 eleman
print(matris.shape)    # (2, 3)   → 2 satır, 3 sütun
print(resim.shape)     # (224, 224, 3) → 3 boyutlu

# Boyut sayısı
print(resim.ndim)      # 3

# Toplam eleman sayısı
print(resim.size)      # 150528 = 224×224×3
⚠️ Shape Uyumu

Sinir ağlarında en sık yapılan hata şekil uyumsuzluğudur: "Model (3, 4) bekliyordu, ben (4, 3) gönderdim" gibi. Modelinize veri beslemeden önce her zaman .shape ile kontrol edin.

İndeksleme: İstediğin Veriyi Seçme

matris = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

print(matris[0])        # [10 20 30] — ilk satır
print(matris[0, 1])     # 20 — 0. satır, 1. sütun
print(matris[:, 1])     # [20 50] — tüm satırlar, 1. sütun
print(matris[1, :])     # [40 50 60] — 1. satır, tüm sütunlar
print(matris[0, 1:])    # [20 30] — 0. satır, 1'den sona kadar

Broadcasting: Farklı Boyutları Uyumlu Hale Getirmek

NumPy, farklı boyutlardaki array'leri otomatik olarak "yayarak" (broadcasting) birlikte çalışabilir hale getirir. Bu, milyonlarca satırı tek satırda işlemenizi sağlar: 

# Her elemana 10 ekleme — NumPy otomatik olarak 10'u her elemana "yayar"
matris = np.array([[1, 2, 3], [4, 5, 6]])
print(matris + 10)
# [[11 12 13]
#  [14 15 16]]

# Sütun vektörü ile satır vektörü toplama (outer-benzeri)
a = np.array([[1], [2], [3]])    # shape (3, 1)
b = np.array([10, 20])           # shape (2,)
print(a + b)
# a her elemanı b'nin her elemanına yayılır:
# [[11 21]
#  [12 22]
#  [13 23]]

İnteraktif: Broadcasting Animasyonu

Aşağıda broadcasting'in nasıl çalıştığını adım adım izleyin: küçük array, büyük array'e her işlem sırasında "kopyalanarak" eşlik eder.

Temel İstatistik

puanlar = np.array([85, 92, 78, 95, 88, 76, 90])

print(np.mean(puanlar))    # Ortalama: 86.28...
print(np.median(puanlar))  # Medyan: 88
print(np.std(puanlar))     # Standart sapma: 6.35...
print(np.min(puanlar))     # En düşük: 76
print(np.max(puanlar))     # En yüksek: 95

# Normalizasyon — çok önemli: model girişlerini aynı ölçeğe getirmek
normal = (puanlar - np.mean(puanlar)) / np.std(puanlar)
# Artık ortalama 0, standart sapma 1 → model daha rahat öğrenir
💡 Normalizasyon Analojisi

Bir sınıfta bazı öğrenciler 100 üzerinden, bazıları 5 üzerinden not almış olsun. Karşılaştırma yapmak için hepsini ortak bir ölçeğe çevirmeniz gerekir. Normalizasyon tam olarak bunu yapar: her veri özelliğini aynı "ölçek cetveline" oturtur.

Resimler Aslında NumPy Array'idir

img = Image.open("kedi.jpg")
arr = np.array(img)
print(arr.shape)   # (yükseklik, genişlik, 3) — 3 = R, G, B kanalları

# R (kırmızı) kanalı al
kirmizi = arr[:, :, 0]

# Gri tonlamaya çevir (basit yöntem)
gri = np.mean(arr, axis=2)
