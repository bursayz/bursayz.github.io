Tokenization: Metni Sayılara Çevirmek

📚 L1 · LLM Serisi⏱ ~25 dakika🖥 İnteraktif Araç
Bu derste öğrenecekleriniz: Modelin metni nasıl gördüğü, BPE algoritması, özel token'lar ve bağlam penceresi. LLM'in "düşünme" sürecinin ilk adımı burada başlar.

Model Metni Nasıl Görür?

Bilgisayarlar sadece sayıları anlar. "Merhaba dünya" yazısı bilgisayar için anlamsızdır — önce sayılara çevrilmesi gerekir. Bu işleme tokenization denir.

"Bursa güzel bir şehir"
→
Tokenization

[15234, 8971, 245, 12908]

Neden Kelime Kelime Değil?

En basit yaklaşım kelime bazlı olurdu ama sorunlu: "koşmak", "koştu", "koşacak" hep farklı kelime sayılır. Kelime haznesi çok büyür ve İngilizce dışındaki dillerde patlar. Alt-kelime (subword) tokenizasyonu dengeyi bulur: sık kullanılan kelimeler tek token, nadir kelimeler parçalara bölünür. 

# tiktoken ile (OpenAI'ın tokenizerı)
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")

metin = "yapay zeka öğreniyorum"
tokenlar = enc.encode(metin)
print(tokenlar)  # [15339, 11561, 91, 1048, 2977, 271, 1239]

# Token ID'si → orijinal parça
for t in tokenlar:
    print(t, "→", enc.decode([t]))

BPE Algoritması: Adım Adım

BPE (Byte Pair Encoding), en sık geçen karakter çiftlerini tekrar tekrar birleştirerek kelime haznesi oluşturur:

  1. Başta her karakter ayrı bir token: ["k","a","n","a","t"]
  2. Veri setinde en çok birlikte geçen çift bulunur: ("a","n") → yeni token "an"
  3. Tüm metinlerde bu çift birleştirilir: ["k","an","a","t"]
  4. Bu adım tekrarlanır... binlerce kez → kelime haznesi oluşur
# Basit BPE simülasyonu
def bpe_egit(metin, birlesme_sayisi):
    tokenlar = list(metin)
    for _ in range(birlesme_sayisi):
        # En sık geçen çifti bul
        siklik = {}
        for i in range(len(tokenlar) - 1):
            cift = (tokenlar[i], tokenlar[i+1])
            siklik[cift] = siklik.get(cift, 0) + 1
        if not siklik: break
        en_sik = max(siklik, key=siklik.get)
        yeni_token = "".join(en_sik)
        # Birleştir
        yeni_tokenlar = []
        i = 0
        while i < len(tokenlar):
            if i < len(tokenlar)-1 and (tokenlar[i], tokenlar[i+1]) == en_sik:
                yeni_tokenlar.append(yeni_token)
                i += 2
            else:
                yeni_tokenlar.append(tokenlar[i])
                i += 1
        tokenlar = yeni_tokenlar
        print(f"Birleşen: {en_sik} → '{yeni_token}'  →  {tokenlar}")
    return tokenlar

bpe_egit("kanat kanat kanat", 3)
# 1. tur: ('a','n') → 'an' → ['k','an','a','t',' ','k','an','a','t',...]
# 2. tur: ('k','an') → 'kan' → ['kan','a','t',...]
# 3. tur: ('a','t') → 'at' → ['kan','at',...]

Bağlam Penceresi (Context Window)

  • Model aynı anda sadece belirli sayıda token "görebilir". Bu limit: bağlam penceresi.
  • GPT-3.5: 4K token, GPT-4: 128K token, Claude 3.5: 200K token.
  • 1 token ≈ 0.75 İngilizce kelime ≈ 0.5-0.6 Türkçe kelime (Türkçe daha çok parçalanır!).
  • Pencere dolunca: eski token'lar "unutulur" veya özetlenir.
⚠️ Türkçe ve Tokenization

Türkçe eklemeli bir dildir — "evlerimizden" = 5 anlamlı morfem (ev+ler+i+miz+den). İngilizce için eğitilen tokenizer Türkçe'yi çok parçalar → daha fazla token, daha yüksek maliyet, daha yavaş çalışma. Türkçe LLM geliştirirken Türkçe tokenizer eğitmek büyük avantaj sağlar.
