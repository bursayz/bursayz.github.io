Görüntü Düzenleme Modeli Yapımı

📚 G7 · Görüntü Serisi⏱ ~35 dakika🖥 İnteraktif Demo
Bu derste öğrenecekleriniz: Maskeleme (inpainting) mantığı, Stable Diffusion Inpainting'in nasıl çalıştığı, InstructPix2Pix ile metin komutuyla düzenleme ve düzenleme veri seti hazırlama.

Inpainting Nedir?

Görüntünün belirli bir bölgesini maskeleyip (örneğin nesneyi işaretleyip) modele "burayı yeniden oluştur" demek. Diffusion modeli hem maskeyi hem orijinal latent'i alır, maskeli bölgeyi bağlama uygun yeniden üretir.

💡 Analoji

Ressam bir tabloda yanlış çizdiği yeri boyar ve üstünü yeniden boyar: üst katman maskelediğiniz alan, alt katman tablonun geri kalanı. Diffusion modeli bu iki katmanı birlikte görür: alt katmanı korur, üst katmanı yeniden yazar — ve kenarları yumuşatarak birleştirir.

SD Inpainting: Diffusion'un Maskeli Hali

# Diffusers ile SD Inpainting kullanımı
from diffusers import StableDiffusionInpaintPipeline
import torch
from PIL import Image

pipe = StableDiffusionInpaintPipeline.from_pretrained(
    "stable-diffusion-v1-5/stable-diffusion-inpainting",
    torch_dtype=torch.float16
).to("cuda")

resim = Image.open("bursa_sahil.jpg").resize((512, 512))
maske = Image.open("maske.png").resize((512, 512))   # Beyaz=değiştir, siyah=koru

sonuc = pipe(
    prompt="gün batımında deniz kenarı, fotoğraf gerçekçi",
    image=resim,
    mask_image=maske,
    num_inference_steps=50,
    guidance_scale=7.5     # Prompt'a ne kadar bağlı kalınacak (CFG)
).images[0]
sonuc.save("duzenlenmis.jpg")

CFG (Classifier-Free Guidance): Prompta Ne Kadar Bağlı?

  • guidance_scale=1: Promptu görmezden gelir — saf diffusion üretimi.
  • guidance_scale=7.5 (tipik): Prompt + görsel bağlam dengesi.
  • guidance_scale=20: Prompt'a aşırı sadakat — doygun, "rüya gibi" görüntüler.
# CFG mantığı: iki tahmin hesaplanır
# eps_kosulsuz = model(x_t, t)           # Prompt'suz
# eps_kosullu  = model(x_t, t, prompt)   # Prompt'lu
# Sonuç = eps_kosulsuz + scale × (eps_kosullu - eps_kosulsuz)
# Fark vektörü büyütülür → yönlendirme güçlenir

InstructPix2Pix: "Bunu Değiştir" Komutları

from diffusers import StableDiffusionInstructPix2PixPipeline

pipe = StableDiffusionInstructPix2PixPipeline.from_pretrained(
    "timbrooks/instruct-pix2pix").to("cuda")

# Maske YOK — doğal dil komutu:
sonuc = pipe(
    prompt="kırmızı arabayı mavi yap",
    image=resim,
    num_inference_steps=50,
    image_guidance_scale=1.5,   # Orijinal görüntüye sadakat
    guidance_scale=7.0
).images[0]

InstructPix2Pix veri seti GPT-3 tarafından üretilen (talimat, öncesi, sonrası) üçlülerinden oluşur: ("bulutları kaldır", bulutlu resim, açık gökyüzü) gibi. Milyonlarca yapay düzenleme örneği sentetik olarak üretilip gerçek diffusion modeliyle oluşturuldu.

Düzenleme Veri Seti Hazırlama

Kendi InstructPix2Pix tarzı modelinizi eğitmek isterseniz:

  1. Bir dizi orijinal resim toplayın (binlerce)
  2. GPT-4 gibi bir LLM ile "düzenleme talimatları" üretin: "gözlüğü kaldır", "saçı kızıla boya"...
  3. Her talimat için hedef resmi diffusion ile üretin (talimat + orijinal → düzenlenmiş)
  4. InstructPix2Pix örneğindeki gibi (talimat, input_latent, output_latent) üçlüleriyle eğitin
