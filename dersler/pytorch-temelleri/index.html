Bu derste öğrenecekleriniz: Tensor nedir, PyTorch ile temel işlemler, autograd (otomatik türev), nn.Module ile model sınıfı yazma ve DataLoader ile veri besleme. İlk gerçek model kodunuzu yazacaksınız.

PyTorch Nedir ve Neden Tercih Ediliyor?

PyTorch, Meta (Facebook) tarafından geliştirilen, günümüzde akademik araştırmanın ve endüstrinin en yaygın derin öğrenme kütüphanesidir. TensorFlow ile karşılaştırıldığında Python ile daha doğal hisseden API'si ve dinamik hesap grafiği sayesinde araştırma dünyasında standart hale geldi. 

# Kurulum: pip install torch
import torch
print(torch.__version__)           # 2.x.x
print(torch.cuda.is_available())   # True ise GPU var!

Tensor: PyTorch'un Veri Yapısı

Tensor, NumPy array'inin PyTorch karşılığıdır — ama ekstra autograd (türev takibi) ve GPU desteği sunar. 

import torch

# Tensor oluşturma
x = torch.tensor([1.0, 2.0, 3.0])                    # 1D
y = torch.tensor([[1, 2], [3, 4]], dtype=torch.float32)  # 2D
z = torch.zeros(3, 4)                                  # Sıfırlarla dolu
r = torch.randn(2, 3)                                  # Normal dağılımdan rastgele

# Temel özellikler
print(x.shape)       # torch.Size([3])
print(y.dtype)       # torch.float32
print(x.device)      # cpu veya cuda

# NumPy ile dönüşüm
import numpy as np
arr = np.array([1, 2, 3])
t = torch.from_numpy(arr)   # Numpy → Tensor
arr2 = t.numpy()            # Tensor → Numpy

Temel İşlemler — NumPy ile Neredeyse Aynı

a = torch.tensor([1.0, 2.0, 3.0])
b = torch.tensor([4.0, 5.0, 6.0])

print(a + b)      # [5, 7, 9]
print(a * b)      # Eleman-eleman: [4, 10, 18]
print(a @ b)      # Dot product: 32.0 (= 4+10+18)
print(a.mean())   # 2.0
print(a.sum())    # 6.0

# CPU → GPU (varsa)
if torch.cuda.is_available():
    a = a.to("cuda")
    print(a.device)   # cuda:0

Autograd: Otomatik Türev

PyTorch, her tensor'da yapılan işlemleri izler ve backward() çağrıldığında tüm parametrelerin gradyanlarını (türevlerini) otomatik hesaplar. Bu, sinir ağı eğitiminin motorudur. 

# requires_grad=True ile türev takibini aç
x = torch.tensor(3.0, requires_grad=True)

y = x**2 + 2*x    # y = x² + 2x

# y'nin x'e göre türevi: dy/dx = 2x + 2
y.backward()      # Türevi hesapla

print(x.grad)     # x=3 için: 2(3) + 2 = 8.0
💡 Analoji

Autograd, bir hikaye anlatıcısı gibi çalışır: siz fonksiyonu yazarsınız, PyTorch her işlemi not alır. "Geri dön" dediğinizde, notları ters sırayla okuyarak her parametrenin hataya katkısını hesaplar. Siz zincir kuralını manuel uygulamak zorunda kalmazsınız.

nn.Module ile Model Yazma

import torch
import torch.nn as nn

class BasitSiniflandirici(nn.Module):
    def __init__(self, giris_boyutu, gizli_boyut, sinif_sayisi):
        super().__init__()
        self.katman1 = nn.Linear(giris_boyutu, gizli_boyut)
        self.aktivasyon = nn.ReLU()
        self.katman2 = nn.Linear(gizli_boyut, sinif_sayisi)

    def forward(self, x):
        x = self.katman1(x)
        x = self.aktivasyon(x)
        x = self.katman2(x)
        return x   # Softmax uygulamıyoruz — CrossEntropyLoss kendisi halleder

model = BasitSiniflandirici(784, 128, 10)  # MNIST: 784 piksel → 10 sınıf
print(model)
# BasitSiniflandirici(
#   (katman1): Linear(in_features=784, out_features=128, bias=True)
#   (katman2): Linear(in_features=128, out_features=10, bias=True)
# )

# Kullanım
x = torch.randn(32, 784)   # 32 resim, 784 özellik (28×28)
cikti = model(x)
print(cikti.shape)   # [32, 10] → her resim için 10 sınıf skoru
