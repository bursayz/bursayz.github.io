Sinir Ağları ve Derin Öğrenme

📚 M2 · ML/DL Serisi⏱ ~30 dakika🧊 3D İnteraktif
Bu derste öğrenecekleriniz: Yapay nöron nasıl çalışır, ağırlık ve bias nedir, aktivasyon fonksiyonları neden gereklidir, ileri yayılım (forward pass) nasıl hesaplanır. Bu dersi bitince sinir ağının içini görebileceksiniz.

Biyolojiden Matematiğe: Yapay Nöron

Beyindeki nöron, diğer nöronlardan sinyal alır, toplar ve eşiği aşarsa ateşlenir (sonraki nörona sinyal gönderir). Yapay nöron da aynı fikrin matematiğidir:

Girdiler
x₁, x₂, x₃
Her biri bir sinyal
→
Ağırlıklı Toplam
z = x₁·w₁ + x₂·w₂ + x₃·w₃ + b
(ağırlık + bias)
→
Aktivasyon
a = f(z)
(ReLU, sigmoid...)
→
Çıktı
Bir sonraki katmana sinyal
import numpy as np

def noron(girdiler, agirliklar, bias):
    z = np.dot(girdiler, agirliklar) + bias   # Ağırlıklı toplam
    return max(0, z)  # ReLU aktivasyonu

# Örnek:
girdiler  = np.array([0.5, -0.2, 0.8])
agirliklar = np.array([0.4, 0.9, -0.3])
bias = 0.1

cikti = noron(girdiler, agirliklar, bias)
print(cikti)  # 0.5*0.4 + (-0.2)*0.9 + 0.8*(-0.3) + 0.1 = 0.0 + 0.1 = 0.1

Ağırlık ve Bias: Ayar Düğmeleri

  • Ağırlık (w): Her girdinin "önemini" ayarlar. Büyük w → o girdi kararı daha çok etkiler.
  • Bias (b): Modelin "genel eğilimini" kaydırır. Nöronun temel eşiğini ayarlar.
💡 Analoji

Bir müzik stüdyosundaki mikseri düşünün: her kanalın ses düğmesi (ağırlık), bir de "master volume" (bias). İyi müzik = tüm düğmelerin doğru ayarı. Sinir ağı eğitimi = milyonlarca mikser düğmesinin doğru konumunu bulmaktır.

Aktivasyon Fonksiyonları: Neden Gereklidir?

Aktivasyon fonksiyonu olmazda, kaç katman dizeseniz de sonuç yine tek bir doğrusal fonksiyon gibi davranır — yani öğrenebileceği örüntüler sınırlı kalır. Aktivasyon fonksiyonu doğrusallığı kırar ve karmaşık şekilleri öğrenmeyi mümkün kılar.

ReLU (Rectified Linear Unit)

def relu(x):
    return max(0, x)   # Negatifse 0, pozitifse kendisi

relu(-3)   # 0
relu(5)    # 5
# Günümüzün en yaygın aktivasyonu — basit ve etkili

Sigmoid

def sigmoid(x):
    return 1 / (1 + np.exp(-x))   # 0 ile 1 arasına sıkıştırır

sigmoid(0)     # 0.5
sigmoid(10)    # ≈ 1.0
sigmoid(-10)   # ≈ 0.0
# "Evet/Hayır" kararları için; ama gradyanları küçülür — büyük ağlarda tercih edilmez

Softmax (Çıkış Katmanı İçin)

def softmax(x):
    exp = np.exp(x - np.max(x))   # Stabilite için
    return exp / exp.sum()

softmax(np.array([2.0, 1.0, 0.1]))
# [0.659, 0.242, 0.099] → "%66 kedi, %24 köpek, %9 kuş"

İleri Yayılım (Forward Pass): Sinyalin Yolculuğu

# 2 katmanlı küçük bir sinir ağı — sıfırdan
import numpy as np

class MiniAg:
    def __init__(self):
        self.W1 = np.random.randn(3, 4) * 0.1   # Girdi: 3, Gizli: 4
        self.b1 = np.zeros(4)
        self.W2 = np.random.randn(4, 2) * 0.1   # Gizli: 4, Çıktı: 2
        self.b2 = np.zeros(2)

    def relu(self, x): return np.maximum(0, x)
    def softmax(self, x):
        e = np.exp(x - np.max(x))
        return e / e.sum()

    def ileri(self, x):
        # Katman 1
        z1 = x @ self.W1 + self.b1    # Matris çarpımı + bias
        a1 = self.relu(z1)            # Aktivasyon
        # Katman 2 (çıktı)
        z2 = a1 @ self.W2 + self.b2
        return self.softmax(z2)       # Olasılık dağılımı

# Test
ag = MiniAg()
x = np.array([0.5, 0.8, -0.2])
cikti = ag.ileri(x)
print(cikti)  # [0.52, 0.48] → iki sınıf için olasılıklar

Katman Sayısı ve Derinlik

  • 1 gizli katman: Basit doğrusal sınırlar öğrenir.
  • 2-3 gizli katman: Karmaşık eğri sınırlar, soyut örüntüler.
  • Onlarca katman (Derin Öğrenme): Kenar → şekil → parça → nesne gibi hiyerarşik öğrenme. ResNet-152: 152 katman!

Her katman bir öncekine kıyasla daha soyut özellikleri temsil eder. İlk katman kenarları, ikinci katman şekilleri, sonraki katman nesneleri öğrenir. Bu, "derin" kelimesinin anlamıdır — katman katman soyutlaşma.
