Nesne Tespiti (Object Detection)

📚 G4 · Görüntü Serisi⏱ ~35 dakika
Bu derste öğrenecekleriniz: Sınıflandırma ile tespit farkı, bounding box gösterimi, IoU metriği, tek-aşamalı (YOLO) mimarinin mantığı ve Non-Maximum Suppression (NMS) ile tahminleri temizleme.

Sınıflandırma vs Tespit

SINIFLANDIRMA
"Bu resimde kedi var" (%98)
≠
TESPİT
"Kedi (50,120)-(300,280) bölgesinde, köpek (320,90)-(500,300) bölgesinde"

Sınıflandırıcı tek cevap verir; gerçek görüntülerde birden çok nesne olabilir. Tespit modeli her nesne için konum (bounding box) + sınıf + güven skoru üretir.

Bounding Box Formatı

# İki yaygın format (dikkat: kütüphaneler arasında fark!):
bbox_xyxy = [x1, y1, x2, y2]           # Sol-üst köşe + sağ-alt köşe
bbox_cxywh = [cx, cy, w, h]            # Merkez + genişlik/yükseklik (YOLO kullanır)
bbox_xywh  = [x,  y, w, h]             # Sol-üst + boyut (COCO kullanır)

# Örnek: kedi kutusu
kedi = [50, 120, 250, 160]  # (x1, y1, genişlik=250, yükseklik=160) → COCO formatı

IoU: Kutuların Ne Kadar Üst Üste Bindiği

# Intersection over Union — en kritik metrik:
# tahmin kutusu ile gerçek kutunun kesişimi / birleşimi

def iou(kutu_a, kutu_b):
    x1 = max(kutu_a[0], kutu_b[0]); y1 = max(kutu_a[1], kutu_b[1])
    x2 = min(kutu_a[2], kutu_b[2]); y2 = min(kutu_a[3], kutu_b[3])
    kesisim = max(0, x2 - x1) * max(0, y2 - y1)
    alan_a = (kutu_a[2]-kutu_a[0]) * (kutu_a[3]-kutu_a[1])
    alan_b = (kutu_b[2]-kutu_b[0]) * (kutu_b[3]-kutu_b[1])
    return kesisim / (alan_a + alan_b - kesisim)

# IoU > 0.5 → "doğru tespit" (standart eşik)
# mAP@0.5 = tüm sınıfların ortalama hassasiyeti (IoU=0.5'te)
💡 ANALOJİ

İki kart kutusunu üst üste koyun. Kesişim alanı (ortak kısım) ne kadar büyükse o kadar "öngörüsü" doğru. IoU=1 → mükemmel örtüşme; IoU=0 → hiç temas yok. Model, milyonlarca kutuyu doğru IoU'ya yaklaştırmayı öğrenir.

YOLO: Tek Geçişte Her Yeri Tara

YOLO ("You Only Look Once") görüntüyü ızgara hücrelerine böler; her hücre kendi bölgesindeki nesneleri tek seferde tahmin eder. İki aşamalı yöntemler (R-CNN ailesi: önce "burada bir şey var mı?" bölge önerir, sonra sınıflandırır) daha yavaş ama geleneksel olarak daha hassastır. 

# YOLO çıktısı: her grid hücresi için vektör:
# [nesne_olasılığı, x, y, w, h, sınıf_olasılıkları...]
# 7×7 grid × 2 kutu/hücre × (5 + 20 sınıf) = dev çıktı tensörü

# Ultralytics ile pratik (kurulum: pip install ultralytics)
from ultralytics import YOLO
model = YOLO("yolov8n.pt")   # Hazır eğitilmiş en küçük YOLOv8
sonuclar = model("kedi_kopek.jpg")
for kutu in sonuclar[0].boxes:
    print(f"Sınıf {int(kutu.cls)}: {kutu.xyxy} (güven: {kutu.conf:.2f})")

NMS: Aynı Nesne İçin 5 Kutu Varsa…

Model aynı kediye 5 farklı kutu önerebilir (biraz kaymış versiyonları). NMS (Non-Maximum Suppression) ile tek kutuya indirgenir:

  1. Güven skoru en yüksek kutuyu tut
  2. Onunla IoU > 0.5 olan diğer kutuları sil (aynı nesne demektir)
  3. Kalanlardan tekrarla
