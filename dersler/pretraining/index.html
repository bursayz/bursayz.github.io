Ön Eğitim (Pretraining)

📚 L6 · LLM Serisi⏱ ~30 dakika
Bu derste öğrenecekleriniz: Bir temel model (base model) milyarlarca tokenlik internet verisiyle nasıl eğitilir, eğitim maliyeti nasıl hesaplanır, kayıp eğrileri nasıl okunur ve ölçek yasaları (scaling laws) ne söyler.

Temel Model Nasıl Doğar?

ChatGPT gibi modeller aslında iki aşamalı üründür: temel model (base model) internetin devasa bir kesmini okuyup "bir sonraki token" oyununu öğrenir; sonra ince ayar (sonraki ders) bu ham güce davranış öğretir. Bu derste ilk aşamayı inceliyoruz.

Veri: Modelin Gıdası

# Tipik bir LLM veri karışımı (Llama-3 tarzı):
veri_karisimi = {
    "Common Crawl (web)":  0.60,   # %60 — çeşitlilik
    "Kod (GitHub)":        0.15,   # %15 — mantık, yapı
    "Kitaplar":            0.10,   # %10 — uzun anlatı, edebi dil
    "Wikipedia":           0.05,   # %5  — doğrulanmış bilgi
    "Akademik (arXiv)":    0.05,   # %5  — bilimsel dil
    "Diğer":               0.05,
}
# Karışım oranları bile dikkatle ayarlanır — veri kalitesi > veri miktarı
⚠️ Kritik İlke: Veri Kalitesi

"Ne eklersen onu öğrenir." Spam dolu bir veri seti, spam üreten model demektir. Modern veri hazırlama boru hatları şunları yapar: kopya kaldırma (dedup), kalite skorlaması (heuristik + küçük sınıflandırıcı), PII (kişisel veri) temizliği, ve dil tespiti. Llama-3 ekibi eğitim verisinin hazırlanmasına aylar harcadı.

Hesaplama Maliyeti: FLOPs Matematiği

# Pratik formül: eğitim FLOPs ≈ 6 × N × D
# N = parametre sayısı, D = token sayısı
# 6 = ileri geçiş (2N) + geriye yayılım (4N)

N = 7e9        # 7 milyar parametre (küçük LLM)
D = 1e12       # 1 trilyon token
flops = 6 * N * D
print(f"{flops:.2e} FLOPs")   # 4.2e22 FLOPs

# A100 GPU: ~3e14 FLOP/saniye (FP16 ile)
saniye = flops / 3e14
gun = saniye / 86400
print(f"1 A100 ile: {gun:.0f} gün")     # ~3800 gün — 10 yıl!
print(f"1000 A100 ile: {gun/1000:.1f} gün")  # ~4 gün — yapılabilir
# (Gerçekte verimlilik %40-50'dir; ~1 hafta-2 hafta sürer)

Ölçek Yasaları (Scaling Laws)

2020'de OpenAI ekibi (Kaplan et al.) ve 2022'de DeepMind (Chinchilla) şunu keşfetti: kayıp, model boyutu (N) ve veri miktarı (D) ile öngörülebilir güç yasası izler. DeepMind'ın bulgusu: çoğu model az veriyle aşırı büyük eğitiliyordu — optimum oran ~20 token/parametre (7B model için ~140B token).

Ölçek Yasaları — Kayıp vs Model Boyutu / Veri

Kayıp Eğrisini Okumak

  • Başlangıçta hızlı düşüş: Model dilbilgisi gibi "kolay" örüntüleri öğrenir.
  • Uzun yavaş iniş: Dünya bilgisi ve mantık gibi zor örüntüler. İyileşme hiç bitmez, sadece yavaşlar.
  • Ani yükseliş (spike): LR çok yüksek, bozuk veri batch'i veya donanım hatası. Checkpoint'ten geri dönülür.
  • Düzlük: Daha fazla veri veya daha büyük model gerekir.
💡 Checkpoint Analojisi

Haftalarca süren eğitimde model her N adımda diske kaydedilir (checkpoint). Kayıp patlaması yaşanırsa "son iyi duruma" dönülür. Llama-3 eğitiminde Meta ekibi donanım hatalarıyla (boğucu GPU kümelerinde günde ortalama birkaç arıza) başa çıkmak için otomatik kurtarma sistemleri geliştirdi.
