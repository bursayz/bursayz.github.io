Model Quantization Derinlemesine

📚 U1 · Uzman Serisi⏱ ~35 dakika🎓 Uzman
Bu derste öğrenecekleriniz: Kayan nokta aritmetiği (FP32/FP16/BF16), simetrik/asimetrik quantization, kalibrasyon, PTQ vs QAT ve GGUF format ailesi (Q4_K_M vs Q8_0). Quantization'ın "neden" ve "nasıl"ını derinlemesine kavrayın.

Kayan Nokta Aritmetiğinin Anatomisi

import numpy as np
import torch

# 32-bit float (FP32): 1 sign + 8 exponent + 23 mantissa
x = np.float32(3.14159)
# Bitler: 01000000010010010000111111011010
# İşaret: 0 (+), Üs: 10000000 (2^1), Ondalık: 0.5707...
# Değer: (-1)^0 × 2^(128-127) × 1.5707 = 3.14159

# FP16: 1+5+10 → exponent aralığı dar [2^-14, 2^15]
# BF16: 1+8+7  → FP32'nin exponent aralığında (brain float) ama az mantissa
# FP16 daha hassas küçük sayılarda, BF16 daha geniş aralıkta güvenli
print(torch.tensor(1e5, dtype=torch.float16))  # inf (taşma!)
print(torch.tensor(1e5, dtype=torch.bfloat16)) # 100352.0 (idare eder)
💡 ANALOJİ

FP32 = santimetreli cetvel (hassas ama uzun), FP16 = yarım santimetre, INT8 = 0-255 arası sadece tam sayılar — "hassasiyet kaybı" mantığını görün. Quantization, devasa cetveldeki okumayı en yakın tam sayı çizgilerine oturtmaktır. Her model katmanının kabul edebileceği kayıp farklıdır.

Simetrik vs Asimetrik Quantization

# Simetrik: sıfır noktası 0'a sabitlenir (ağırlıklar genelde sıfır merkezli)
def simetrik_quant(x, bit=8):
    maks = torch.abs(x).max()
    olcek = maks / (2 ** (bit - 1) - 1)  # -127..127
    return torch.clamp(torch.round(x / olcek), -127, 127), olcek

# Asimetrik: min-max arasına eşler (aktivasyonlar tek yönlü olabilir: ReLU ≥ 0)
def asimetrik_quant(x, bit=8):
    mn, mx = x.min(), x.max()
    olcek = (mx - mn) / (2 ** bit - 1)
    sifir_noktasi = torch.round(-mn / olcek)
    return torch.clamp(torch.round(x / olcek + sifir_noktasi), 0, 255), olcek, sifir_noktasi

# W8A8 = ağırlık 8-bit + aktivasyon 8-bit (simetrik × asimetrik kombinasyonu)

Kalibrasyon: Hangi Ölçek?

Quantization'da en kritik karar her tensörün ölçeğini (scale) nasıl seçtiğinizdir:

  • Min-Max: Gözlenen en uç değerlerle ölçek — aykırı değerler (outlier) aralığı şişirir, çözünürlük düşer.
  • Percentile (99.9): Aykırıları kırp — çoğu değer için daha iyi çözünürlük.
  • KL Divergence (TensorRT): Orijinal ve quantize dağılım arasındaki farkı minimize et.
  • Per-channel: Her çıkış kanalına ayrı ölçek — büyük modellerde standart (per-tensor'dan çok daha iyi).

GPTQ ve AWQ: LLM'de PTQ'nun Zirvesi

  • GPTQ: Katman katman, Hessian (2. türev) bilgisini kullanarak quantization hatasını telafi edecek şekilde diğer ağırlıkları ayarlar.
  • AWQ: "Ağırlıkların sadece ~%1'i önemlidir" bulgusu — kritik ağırlıkları koruyup gerisini quantize eder. Ölçeklendirme ile.
  • Her ikisi de 4-bit'te Q4_K_M'den belirgin daha iyi kalite verir ama GPU inference odaklıdır.
