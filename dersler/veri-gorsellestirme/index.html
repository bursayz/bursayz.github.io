Veri Görselleştirme

📚 T5 · Temel Serisi ⏱ ~20 dakika
Bu derste öğrenecekleriniz: Matplotlib ile çizgi/sütun/saçılım grafikleri, histogram ve kutu grafiği, ısı haritası, eksen ve etiket okuryazarlığı, ve en önemlisi: veriyi doğru okumak — çünkü modele bakmadan önce veriye bakmanız gerekir.

Neden Görselleştirme?

Sayı tablosuna bakarak veriyi anlamak neredeyse imkansızdır. Ama aynı veriyi grafik olarak görürseniz örüntüler, aykırı değerler ve sorunlar gözünüze çarpar. Yapay zeka mühendisinin ilk refleksi: modele başlamadan önce veriyi görselleştir.

💡 ANALOJİ

Sayı tablosu, hesap tablosundaki ham sayılar gibidir — her şey oradadır ama örüntüyü göremezsiniz. Görselleştirme ise o sayıların harita üzerinde gösterimi gibidir: aynı bilgi, ama coğrafyayı hemen anlarsınız. "Anscombe'un Dörtlüsü" bu dersin en iyi örneğidir: dört veri setinin istatistikleri neredeyse aynı olsa da grafikleri tamamen farklıdır.

Matplotlib: Python'ın Çizim Aracı

import matplotlib.pyplot as plt
import numpy as np

# Basit çizgi grafiği
x = np.linspace(0, 10, 100)         # 0-10 arası 100 nokta
y = np.sin(x)

plt.plot(x, y, label="sin(x)", color="steelblue")
plt.title("Sinüs Dalgası")
plt.xlabel("X ekseni (radyan)")
plt.ylabel("Y ekseni")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

Nesne Yönelimli Kullanım (fig, ax)

Birden fazla grafiği yönetmek veya daha fazla kontrol için fig, ax = plt.subplots() kalıbını kullanın. plt.subplot() eskimiş sayılır. 

# Modern, önerilen yol: fig ve ax nesneleri
fig, ax = plt.subplots(figsize=(8, 5))

ax.plot(x, y, label="sin(x)")
ax.set_title("Sinüs Dalgası")
ax.set_xlabel("X (radyan)")
ax.set_ylabel("Y")
ax.legend()
ax.grid(True, alpha=0.3)

plt.show()

Yaygın Grafik Türleri

import numpy as np
import matplotlib.pyplot as plt

# --- 1. Çizgi grafiği — zaman serisi, eğitim eğrileri ---
epochs = np.arange(1, 21)
np.random.seed(42)
train_loss = 1.0 * np.exp(-0.15 * epochs) + np.random.normal(0, 0.02, len(epochs))
val_loss   = 1.0 * np.exp(-0.12 * epochs) + np.random.normal(0, 0.03, len(epochs)) + 0.05

plt.plot(epochs, train_loss, label="Eğitim")
plt.plot(epochs, val_loss, label="Doğrulama")
plt.xlabel("Epoch")
plt.ylabel("Kayıp")
plt.legend()
plt.title("Eğitim vs Doğrulama Kaybı")
plt.grid(True, alpha=0.3)
plt.show()
# → Overfitting'i burada görürsünüz!

# --- 2. Sütun grafiği — kategori karşılaştırma ---
# Not: Bu skorlar varsayımsal örnek veridir, gerçek benchmark değildir.
modeller = ["LLaMA", "Qwen", "Mistral"]
skorlar  = [87, 85, 83]
plt.bar(modeller, skorlar, color=["#4C72B0", "#55A868", "#C44E52"])
plt.ylabel("Performans Skoru (%)")
plt.title("Model Karşılaştırması (Varsayımsal Veri)")
plt.ylim(0, 100)  # ← Sütun grafiklerinde 0'dan başlatmak önemlidir
plt.show()

# --- 3. Saçılım grafiği — ilişki analizi ---
np.random.seed(42)
boylar     = np.random.normal(170, 10, 50)          # cm
agirliklar = 0.9 * boylar - 70 + np.random.normal(0, 5, 50)
plt.scatter(boylar, agirliklar, alpha=0.6, color="steelblue")
plt.xlabel("Boy (cm)")
plt.ylabel("Ağırlık (kg)")
plt.title("Boy-Ağırlık İlişkisi")
plt.grid(True, alpha=0.3)
plt.show()

# --- 4. Isı haritası (heatmap) — confusion matrix ---
conf_matrisi = np.array([
    [45, 3,  2],
    [2,  38, 5],
    [1,  2,  42]
])
plt.imshow(conf_matrisi, cmap="Blues")
plt.colorbar(label="Tahmin Sayısı")
plt.xticks([0,1,2], ["Kedi", "Köpek", "Kuş"])
plt.yticks([0,1,2], ["Kedi", "Köpek", "Kuş"])
plt.xlabel("Tahmin Edilen Sınıf")
plt.ylabel("Gerçek Sınıf")
plt.title("Karışıklık Matrisi")
plt.show()

Isı Haritası: Confusion Matrix

Yapay zekada en çok göreceğiniz görselleştirme ısı haritasıdır: her hücre bir sayı, rengin sıcaklığı sayıyı temsil eder. Aşağıdaki örnekte hücre içi değerleri de yazdırıyoruz — renk tek başına yeterli değildir. 

import numpy as np
import matplotlib.pyplot as plt

# Confusion matrix: model hangi sınıfı hangi sınıfla karıştırıyor?
# Örnek: 3 sınıflı bir model (kedi, köpek, kuş)
# Satır = Gerçek sınıf, Sütun = Tahmin edilen sınıf
conf = np.array([
    [45, 3,  2],     # Gerçek kedi → 45 doğru, 3 köpek tahmin, 2 kuş tahmin
    [2,  38, 5],     # Gerçek köpek → 2 kedi, 38 doğru, 5 kuş
    [1,  2,  42]     # Gerçek kuş → 1 kedi, 2 köpek, 42 doğru
])

plt.figure(figsize=(6, 5))
plt.imshow(conf, cmap="Blues")

# Hücre değerlerini yazdır — seaborn.heatmap(annot=True) ile aynı işlev
for i in range(3):
    for j in range(3):
        plt.text(j, i, conf[i, j], ha="center", va="center",
                 color="white" if conf[i, j] > conf.max()/2 else "black",
                 fontsize=14, fontweight="bold")

plt.xticks([0,1,2], ["Kedi", "Köpek", "Kuş"])
plt.yticks([0,1,2], ["Kedi", "Köpek", "Kuş"])
plt.xlabel("Tahmin Edilen Sınıf")   # ← eksen etiketi şart
plt.ylabel("Gerçek Sınıf")          # ← eksen etiketi şart
plt.title("Karışıklık Matrisi")
plt.colorbar(label="Tahmin Sayısı")
plt.show()
⚠️ YANILTICI GRAFİKLER

Eksenleri oynayarak aynı veriyi tamamen farklı gösterebilirsiniz. Sütun grafiklerinde Y eksenini 0'dan başlatmamak küçük farkları dramatik gösterir. Ancak çizgi ve saçılım grafiklerinde 0'dan başlamak çoğu zaman veriyi ezer; örneğin 36,5–37,5 °C arası bir sıcaklık serisini 0'dan başlatırsanız hiçbir şey görünmez. Grafik okurken her zaman eksen aralıklarını kontrol edin.

Veri Keşfi: Modele Başlamadan Önce

Eğitim kaybı ve karışıklık matrisi model sonrası araçlardır. Asıl kritik adım: veri setinizi daha modele dokunmadan görselleştirmek. 

import numpy as np
import matplotlib.pyplot as plt

# Örnek veri üret
np.random.seed(42)
veri_normal = np.random.normal(50, 10, 200)
veri_aykiri = np.concatenate([veri_normal, [150, 160, -30]])  # aykırı değerler

# 1. Histogram — dağılımı ve aykırı değerleri gör
fig, ax = plt.subplots(1, 2, figsize=(12, 4))

ax[0].hist(veri_aykiri, bins=30, color="steelblue", edgecolor="white")
ax[0].set_title("Histogram — Veri Dağılımı")
ax[0].set_xlabel("Değer")
ax[0].set_ylabel("Frekans")

# 2. Kutu grafiği (boxplot) — aykırı değerleri işaretler
ax[1].boxplot(veri_aykiri, vert=False)
ax[1].set_title("Kutu Grafiği — Aykırı Değerler")
ax[1].set_xlabel("Değer")

plt.tight_layout()
plt.show()

# 3. Korelasyon ısı haritası — değişkenler arası ilişki
ozellikler = np.random.normal(0, 1, (100, 4))
ozellikler[:, 2] = ozellikler[:, 0] * 0.8 + np.random.normal(0, 0.3, 100)
korelasyon = np.corrcoef(ozellikler.T)

plt.imshow(korelasyon, cmap="RdBu_r", vmin=-1, vmax=1)
plt.colorbar(label="Korelasyon Katsayısı")
plt.xticks(range(4), [f"Özellik {i+1}" for i in range(4)])
plt.yticks(range(4), [f"Özellik {i+1}" for i in range(4)])
plt.title("Korelasyon Isı Haritası")
plt.show()

Veriyi Doğru Okumak: Anscombe'un Dörtlüsü

1973'te istatistikçi Anscombe, dört veri seti yayımladı. Dördünün de ortalaması, varyansı, korelasyonu ve doğrusal regresyon eğimi neredeyse aynıydı. Ama grafikleri tamamen farklıydı: biri doğrusal, biri eğri, biri aykırı değerli, biri tek nokta. İstatistikler yalan söyleyebilir; grafikler gerçeği gösterir.

⚠️ KORELASYON ≠ NEDENSELLİK

Dondurma satışları ile boğulma vakaları birlikte artar — ama biri diğerine neden olmaz; ikisi de yaz mevsiminden etkilenir. Grafikte ilişki görmek, "A, B'ye neden oluyor" demek değildir.

İnteraktif: Farklı Görselleştirme Türleri

Aşağıda aynı veri setinin üç farklı görselleştirmesini görüyorsunuz. Her birinin hangi soruyu yanıtladığını inceleyin.

Veri Görselleştirme Türleri — Canlı Örnek

Eğitim Sürecini Görselleştirmek

import numpy as np
import matplotlib.pyplot as plt

# Örnek eğitim verisi üret (gerçek model çıktısı yerine simülasyon)
np.random.seed(42)
epochs = np.arange(1, 31)
train_losses = 1.0 * np.exp(-0.12 * epochs) + np.random.normal(0, 0.01, len(epochs))
val_losses   = np.concatenate([
    1.0 * np.exp(-0.10 * epochs[:15]) + np.random.normal(0, 0.02, 15),
    0.25 + 0.02 * (epochs[15:] - 15) + np.random.normal(0, 0.02, 15)
])
train_accs = 1 - train_losses
val_accs   = np.concatenate([
    1 - val_losses[:15],
    np.maximum(0.75 - 0.005 * (epochs[15:] - 15), 0.70)  # accuracy bir süre daha artabilir
])

fig, ax = plt.subplots(1, 2, figsize=(12, 4))

ax[0].plot(epochs, train_losses, label="Eğitim Kaybı")
ax[0].plot(epochs, val_losses, label="Doğrulama Kaybı")
ax[0].set_title("Kayıp Eğrileri")
ax[0].set_xlabel("Epoch")
ax[0].legend()
ax[0].grid(True, alpha=0.3)

ax[1].plot(epochs, train_accs, label="Eğitim Doğruluğu")      # ← dilbilgisi düzeltildi
ax[1].plot(epochs, val_accs, label="Doğrulama Doğruluğu")
ax[1].set_title("Doğruluk Eğrileri")
ax[1].set_xlabel("Epoch")
ax[1].legend()
ax[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

Overfitting'i okurken dikkat: Doğrulama kaybı yükselirken doğruluk (accuracy) bir süre daha artabilir — loss ve accuracy aynı anda bozulmayabilir. Ayrıca doğrulama kaybının durağanlaşması (plateau) da erken durdurma sinyali olabilir; mutlaka yükselmesi gerekmez.
