RLHF ve DPO: Davranış Öğretmek

📚 L9 · LLM Serisi⏱ ~35 dakika
Bu derste öğrenecekleriniz: SFT'nin ötesinde hizalama (alignment): insan tercihleriyle ödül modeli eğitmek, PPO ile pekiştirmeli öğrenme ve daha basit modern alternatif DPO. ChatGPT'nin "kibar" olmasının arkasındaki son katman.

SFT Neden Yetmez?

SFT, modele "insanların nasıl cevap verdiğini" öğretir ama tek cevabı temsil eder. Gerçekte birçok cevap "doğru"dur — bazıları diğerlerinden daha yararlı, daha net, daha güvenli. Hizalama (alignment) aşaması, insanların tercih ettiği cevap biçimini öğrenir.

💡 ANALOJİ

SFT doktora "doğru cevabı" verir. RLHF ona "hastaların beğenisini" öğretir: iki doktor da reçete yazabilir ama biri hastasını korkutmadan anlatır. "İyi olmak" teknik bilgi değil, tercih öğrenimidir.

RLHF Üç Aşaması

1. TERCİH VERİSİ
Aynı soruya 2 cevap → insan "A'yı tercih ederim" der
→
2. ÖDÜL MODELİ
İnsan tercihlerini taklit eden skorlayıcı model eğitilir
→
3. PPO EĞİTİMİ
LLM, ödül modelinden yüksek skor alacak şekilde güncellenir

Ödül Modeli (Reward Model)

# Ödül modeli = SFT modelinden türetilen, cevaba "skor" veren model
# Eğitim: insan tercih verisiyle
# Girdi: (prompt, cevap) → Çıktı: skor (yüksek = iyi)

# Bradley-Terry kaybı: tercih edilen cevabın skoru > diğeri olsun
kayip = -torch.log(torch.sigmoid(r_secilen - r_reddedilen)).mean()
# r_secilen: tercih edilen cevabın skoru
# r_reddedilen: reddedilen cevabın skoru
# Model, tercih sıralamasını öğrenir.

PPO: Pekiştirmeli Öğrenme ile LLM Eğitimi

# PPO döngüsü (basitleştirilmiş):
# 1. Politika (LLM) cevap üretir
# 2. Ödül modeli cevaba skor verir
# 3. Yüksek skorlu cevapların olasılığı artırılır

# KL cezası: modelin SFT modelinden çok uzaklaşmasını önler
odul = odul_modeli(prompt, cevap) - beta * KL(politika, referans_model)
# beta ~0.1: "özgür kal ama köklerinden kopma"

# PPO'nun avantajı: online — model kendi ürettiği cevaplardan öğrenir
# Dezavantajı: karmaşık, dengesiz, hiperparametre hassas

DPO: Ödül Modeli Olmadan Hizalama

2023'te Stanford ekibi (DPO) şunu gösterdi: insan tercih verisinden doğrudan LLM'i güncelleyebilirsiniz — ödül modeli ve PPO'ya gerek yok! 

from trl import DPOTrainer, DPOConfig

# DPO veri seti: her satır (prompt, chosen, rejected)
veri = [
    {"prompt": "Kediler neden mırıldar?",
     "chosen":  "Kediler mırıldar çünkü... (yardımcı, nazik, detaylı)",
     "rejected": "Bilmiyorum. (kısa, yararsız)"},
    # ... binlerce örnek
]

ayarlar = DPOConfig(
    beta=0.1,  # Referans modele bağlılık — yüksek beta = daha az sapma
    learning_rate=5e-7,
    per_device_train_batch_size=2
)

egitmen = DPOTrainer(model=model, ref_model=None, args=ayarlar, train_dataset=veri)
egitmen.train()
# ref_model=None → LoRA kullanıyorsanız otomatik referans yaratılır

⚠️ DPO'NUN SINIRI

DPO "kapalı kapı" verisidir: sadece hazır tercih çiftleriyle öğrenir. RLHF online'dır: model kendi cevaplarını üretip puanlanmayı bekler — zamanla daha zorlu durumlara adapte olabilir. Büyük laboratuvarlar (OpenAI, Anthropic) hâlâ RLHF varyantları kullanır; küçük ekipler için DPO neredeyse her zaman daha pratiktir.

İnteraktif: Tercih → Ödül → Politika Döngüsü
