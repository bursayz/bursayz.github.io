Görüntü Sınıflandırma Modeli Yapımı

📚 G2 · Görüntü Serisi⏱ ~40 dakika🖥 İnteraktif Demo
Bu derste öğrenecekleriniz: MNIST veri setiyle uçtan uca bir CNN sınıflandırıcı eğitmek — veri yükleme ve inceleme, model tanımı, eğitim döngüsü, karışıklık matrisi ile hata analizi ve hatalı tahminleri tek tek görüntüleme. Bu dersin sonunda modeli Google Colab'da (ücretsiz GPU) eğitebilecek ve kendi çizdiğiniz rakamı sınıflandırabileceksiniz.
Ön koşul: G1 — CNN Temelleri dersini bitirmiş olmanız önerilir.

End-to-End Proje: Rakam Tanıma (MNIST)

MNIST: 28×28 gri el yazısı rakam (0-9) veri seti — 60.000 eğitim, 10.000 test örneği. Yapay zekânın "Merhaba Dünya"sıdır: küçük ama gerçek bir derin öğrenme problemidir. Bu derste sıfırdan bir CNN kurup ~%99 doğruluğa 3 dakikada ulaşacağız.

Adım 1: Veri Yükleme ve İnceleme

Model kurmadan önce veriye bakmak birinci kuraldır. Bozuk etiket, dengesiz sınıf, garip ölçek — hepsini ancak görerek yakalarsınız.

import torch
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([
    transforms.ToTensor(),                      # PIL [0,255] -> float [0,1] ve (C,H,W) yapar
    transforms.Normalize((0.1307,), (0.3081,))  # MNIST ortalama/std
])

train_data = datasets.MNIST("./data", train=True,  download=True, transform=transform)
test_data  = datasets.MNIST("./data", train=False, download=True, transform=transform)

train_loader = DataLoader(train_data, batch_size=64, shuffle=True)
test_loader  = DataLoader(test_data,  batch_size=256)

print(len(train_data), len(test_data))   # 60000 10000
print(train_data[0][0].shape)            # torch.Size([1, 28, 28])
# Veriyi görün: ilk 16 eğitim örneği
import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 8, figsize=(12, 3))
for ax, (img, etiket) in zip(axes.flat, train_data):
    ax.imshow(img.squeeze(), cmap="gray")
    ax.set_title(str(etiket), fontsize=10)
    ax.axis("off")
plt.tight_layout()
plt.show()

# Sınıf dağılımı dengeli mi?
import collections
sayac = collections.Counter(int(etiket) for _, etiket in train_data)
print(sayac)  # her rakamdan ~6000 adet — dengeli ✓
💡 Normalize neden?

ToTensor() pikselleri 0-1 aralığına çeker. Normalize ise her pikselden veri setinin ortalamasını (0.1307) çıkarıp standart sapmasına (0.3081) böler; böylece girişler ortalama 0, std 1 civarında dağılır. Bu, gradyan inişinin ilk adımlarını dengeler ve eğitimi hızlandırır. Sayılar MNIST'in önceden hesaplanmış gerçek istatistikleridir — CIFAR-10 için farklıdır (aşağıya bakın).

Adım 2: CNN Model Tanımı

Model iki evrişim bloğu + iki tam bağlı katman: conv → relu → pool, iki kez; sonra düzleştir ve sınıflandır. 

import torch.nn as nn

class RakamSiniflandirici(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, padding=1)   # 1->32 kanal, 3x3
        self.conv2 = nn.Conv2d(32, 64, 3, padding=1)  # 32->64 kanal
        self.pool = nn.MaxPool2d(2, 2)                # 2x küçültme
        self.fc1 = nn.Linear(64 * 7 * 7, 128)         # 64*7*7 = 3136
        self.fc2 = nn.Linear(128, 10)                 # 10 rakam sınıfı
        self.dropout = nn.Dropout(0.25)
        self.relu = nn.ReLU()

    def forward(self, x):
        x = self.pool(self.relu(self.conv1(x)))  # 28 -> 14
        x = self.pool(self.relu(self.conv2(x)))  # 14 -> 7
        x = torch.flatten(x, 1)                  # (B, 3136)
        x = self.dropout(self.relu(self.fc1(x)))
        return self.fc2(x)                       # ham skorlar (logits)

model = RakamSiniflandirici()
toplam = sum(p.numel() for p in model.parameters())
print(f"Parametre sayısı: {toplam:,}")   # 421,642

Veri akışı: şekil takibi

(1, 28, 28)girdi → (32, 28, 28)conv1+relu → (32, 14, 14)pool → (64, 14, 14)conv2+relu → (64, 7, 7)pool → (3136)flatten → (128)fc1+relu → (10)fc2 (logit)

Dikkat: parametrelerin %95'i fc1'de, iki konvolüsyonda toplamda sadece ~19K var. CNN'in gücü tam da bu — görüntüyü ucuz, paylaşımlı filtrelerle işler; ağır işi en sonda, zaten özetlenmiş özellik üzerindeki tek tam bağlı katman yapar.

Adım 3: Eğitim Döngüsü

torch.manual_seed(42)   # tekrarlanabilirlik
device = "cuda" if torch.cuda.is_available() else "cpu"
model = model.to(device)

optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.CrossEntropyLoss()   # içinde log_softmax var — ayrı softmax EKLEMEYİN

for epoch in range(3):            # epoch: tüm eğitim verisinin 1 turu
    model.train()
    toplam_kayip = 0
    for X, y in train_loader:
        X, y = X.to(device), y.to(device)
        optimizer.zero_grad()          # gradyanları sıfırla
        kayip = loss_fn(model(X), y)   # ileri geçiş
        kayip.backward()               # geriye yayılım: gradyan hesapla
        optimizer.step()               # ağırlıkları güncelle
        toplam_kayip += kayip.item()
    print(f"Epoch {epoch+1}: kayıp={toplam_kayip/len(train_loader):.4f}")

zero_grad → forward → backward → step sırası standarttır ve her adım gereklidir:

  • zero_grad() unutulursa gradyanlar bir önceki batch'e eklenir; eğitim kontrolsüz şişer.
  • backward() kaybın her parametreye göre türevini hesaplar.
  • step() Adam kuralıyla ağırlıkları bu türevlerin tersi yönünde bir adım kaydırır.

Beklenen çıktı (Colab T4 GPU, ~1-2 dk):

Epoch 1: kayıp=0.1420
Epoch 2: kayıp=0.0451
Epoch 3: kayıp=0.0312
💡 Sağlık kontrolü

10 sınıflı rastgele tahminin başlangıç kaybı teorik olarak ln(10) ≈ 2.30'dur. İlk batch'lerde kayıp bundan çok yüksek veya NaN ise veri/etiket hattında bir sorun vardır. 3 epoch MNIST için yeterlidir; fazlası test doğruluğunu artırmaz, overfitting riskini artırır (dropout bu yüzden var).

Adım 4: Değerlendirme ve Karışıklık Matrisi

from sklearn.metrics import confusion_matrix, classification_report
import numpy as np

model.eval()   # dropout'u kapat, BatchNorm varsa running istatistik kullan
tum_tahminler, tum_gercekler = [], []

with torch.no_grad():
    for X, y in test_loader:
        tahmin = model(X.to(device)).argmax(dim=1).cpu()
        tum_tahminler.extend(tahmin.tolist())
        tum_gercekler.extend(y.tolist())

dogruluk = np.mean(np.array(tum_tahminler) == np.array(tum_gercekler))
print(f"Test doğruluğu: %{dogruluk*100:.2f}")   # ~%99 beklenir

conf = confusion_matrix(tum_gercekler, tum_tahminler)
print(classification_report(tum_gercekler, tum_tahminler, digits=3))

Matrisi ekrana çizdirelim — köşegen dışı koyu hücreler = hangi rakamlar karışıyor:

import seaborn as sns

fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(conf, annot=True, fmt="d", cmap="Blues", cbar=False, ax=ax)
ax.set_xlabel("Tahmin"); ax.set_ylabel("Gerçek")
ax.set_title("Karışıklık Matrisi (satır=gerçek, sütun=tahmin)")
plt.show()

Tipik çıktıda diyagonal ~1000'er civarındadır; en büyük karışıklıklar 4↔9 ve 3↔8 gibi gerçekten birbirine benzeyen çiftlerdedir. Bu "mantıklı hata"dır: model rasgele yanılmıyor, el yazısındaki benzerliği yakalıyor.

Hatalı Örnekler: Modelin Gözünden

Test setinde yanlış tahmin edilen örneklere bakmak, modelin zayıf noktasını anlamanın en iyi yoludur:

# 1) Tahminleri ve softmax güvenlerini topla
tum_X, tum_y, guvenler = [], [], []
with torch.no_grad():
    for X, y in test_loader:
        logits = model(X.to(device))
        prob = torch.softmax(logits, dim=1)
        tum_X.append(X); tum_y.append(y)
        guvenler.append(prob.max(dim=1).values.cpu())
guvenler = torch.cat(guvenler)

tum_tahminler = torch.tensor(tum_tahminler)
yanlis_idx = (tum_tahminler != torch.tensor(tum_gercekler)).nonzero().flatten()

# 2) En güvenli 16 yanlışı göster (yüksek güven + yanlış = en öğretici)
siralama = yanlis_idx[guvenler[yanlis_idx].argsort(descending=True)]
fig, axes = plt.subplots(4, 4, figsize=(8, 8))
for ax, i in zip(axes.flat, siralama[:16]):
    img, gercek = test_data[i]
    ax.imshow(img.squeeze(), cmap="gray")
    ax.set_title(f"gerçek:{gercek} tahmin:{tum_tahminler[i]} (%{guvenler[i]*100:.0f})", fontsize=9)
    ax.axis("off")
plt.tight_layout()
plt.show()

Genellikle el yazısı gerçekten belirsizdir — yamuk 4, kapalı 9, yarım 5 gibi. Bu "mantıklı hata"dır; veri artırma veya biraz daha derin modelle azaltılabilir.

Bir Sonraki Adım: CIFAR-10

Aynı kodu CIFAR-10 (32×32 renkli, 10 sınıf: uçak, araba, kedi...) ile denemek isterseniz üç noktayı değiştirmeniz gerekir; aksi hâlde RuntimeError alırsınız: 

# 1) Girdi 3 kanallı olmalı:
self.conv1 = nn.Conv2d(3, 32, 3, padding=1)

# 2) 32x32 olduğu için düzleştirme boyutu 64*8*8:
# (32 -> pool 16 -> pool 8)
self.fc1 = nn.Linear(64 * 8 * 8, 128)

# 3) Normalize istatistikleri farklı:
transforms.Normalize((0.4914, 0.4822, 0.4465),
                     (0.2470, 0.2435, 0.2616))

Sık Yapılan Hatalar

  • zero_grad() atlamak → gradyanlar birikir, eğitim bozulur.
  • model.eval() unutmak → dropout hep açık kalır, test doğruluğu düşer.
  • Veri ile modeli farklı cihaza (CPU/GPU) koymak → RuntimeError: Expected all tensors....
  • CrossEntropyLoss öncesi ayrıca softmax eklemek → çift softmax, sayısal kararsızlık.
  • shuffle=True'yu test loader'da da açmak → karışıklık matrisi indeksleri kayar.

Egzersizler

  1. Epoch sayısını 1 ve 10 yapın; eğitim/test kaybı grafiğini çizin. Overfitting'i görün.
  2. lr'yi 1e-1 ve 1e-5 yapın. Ne olur, neden?
  3. Üçüncü bir konv bloğu ekleyin (Conv2d(64,128,3,padding=1)); parametre sayısı ve doğruluk değişimini not edin.
  4. Aynı mimariyi Fashion-MNIST (datasets.FashionMNIST) ile çalıştırın; kıyafet sınıflarını ayırt edin.
