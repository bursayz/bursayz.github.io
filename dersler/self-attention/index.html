Self-Attention: Model Nereye Bakıyor?

📚 L3 · LLM Serisi⏱ ~35 dakika🧊 3D İnteraktif
Bu derste öğrenecekleriniz: Query/Key/Value kavramları, attention skorunun nasıl hesaplandığı, softmax, nedensel maskeleme ve çok başlık dikkat. Transformer'ın gücünün kaynağı burasıdır.

Problem: Kelime Anlamı Bağlama Bağlıdır

"Bank" kelimesini düşünün: "nehir kenarındaki bank" vs "para çekmek için banka". Aynı kelime, farklı anlam. Model anlamı çözmek için etrafındaki kelimelere bakmalı. Self-attention tam olarak bunu yapar: her kelimeye, cümledeki diğer tüm kelimelerle ne kadar ilişkili olduğunu sorar.

💡 Analoji

Kalabalık bir partide bir konuşmayı yakalamaya çalışıyorsunuz. Herkes aynı anda konuşuyor ama siz beyninizi önemli kaynaklara odaklıyorsunuz. Self-attention: her kelime, diğer kelimelere "benim için ne kadar önemlisin?" diye sorar ve cevabına göre onlardan bilgi toplar. Önemsiz kelimeler = kısık ses, önemli kelimeler = yüksek ses.

Query, Key, Value

Her kelime için üç vektör üretiriz:

import torch
import torch.nn as nn

embed_dim = 64
Q = nn.Linear(embed_dim, embed_dim, bias=False)  # Sorgu vektörü
K = nn.Linear(embed_dim, embed_dim, bias=False)  # Anahtar vektörü
V = nn.Linear(embed_dim, embed_dim, bias=False)  # Değer vektörü

# girdi: (seq_len, embed_dim) — her kelime için 64 boyutlu embedding
# Q(x): "Ben ne arıyorum?" (Query)
# K(x): "Benim anlamım / içeriğim nedir?" (Key)
# V(x): "Sana ne bilgi sunabilirim?" (Value)

Attention Formülü

# Attention(Q, K, V) = softmax(Q @ K.T / sqrt(d_k)) @ V
#
# Adım adım:
#
# 1. Q @ K.T  → attention skorları (seq_len × seq_len matrisi)
#    - Her kelime her kelimeyle skor hesaplar
#    - Büyük skor = çok ilişkili
#
# 2. / sqrt(d_k)  → ölçekleme (gradyanların stabilitesi için)
#    - d_k = 64 → sqrt(64) = 8 ile böl
#
# 3. softmax  → satır toplamını 1 yap
#    - Her kelime toplamda %100 dikkat dağıtır
#
# 4. @ V  → ağırlıklı değer toplamı
#    - Skorlar yüksek olan kelimelerden daha çok bilgi al

def attention(x, Q, K, V):
    q, k, v = Q(x), K(x), V(x)      # (seq, dim)
    dk = x.shape[-1]
    skor = q @ k.T / dk**0.5         # (seq, seq)
    agirliklar = torch.softmax(skor, dim=-1)  # (seq, seq)
    return agirliklar @ v            # (seq, dim)

Nedensel Maskeleme (Causal Masking)

Dil modeli metni soldan sağa ürettiği için, kelime t+1'inci kelimeye bakamaz (geleceği göremez). Nedensel maskeleme bunu engeller: 

seq_len = 4
maske = torch.tril(torch.ones(seq_len, seq_len))
# Alt üçgen: 1. kelime sadece kendini görür, 2. kendisi + 1., vs.
# [[1, 0, 0, 0],
#  [1, 1, 0, 0],
#  [1, 1, 1, 0],
#  [1, 1, 1, 1]]

skor = skor.masked_fill(maske == 0, float("-inf"))
# -inf → softmax sonrası 0 olur → gelecek kelimelere bakılamaz
agirliklar = torch.softmax(skor, dim=-1)

Çok Başlık Dikkat (Multi-Head Attention)

Tek bir attention başlığı tek bir ilişki türünü öğrenir (örn. özne-nesne). Çok başlık dikkat, kelime uzayını parçalara bölerek her parçada farklı ilişki türleri öğrenir: 

class MultiHeadAttention(nn.Module):
    def __init__(self, embed_dim=64, n_bas=4):
        super().__init__()
        self.n_bas = n_bas
        self.bas_dim = embed_dim // n_bas   # 64/4 = 16 boyut per baş
        self.Q = nn.Linear(embed_dim, embed_dim, bias=False)
        self.K = nn.Linear(embed_dim, embed_dim, bias=False)
        self.V = nn.Linear(embed_dim, embed_dim, bias=False)
        self.proj = nn.Linear(embed_dim, embed_dim, bias=False)

    def forward(self, x):
        B, T, C = x.shape   # batch, seq, dim
        q = self.Q(x).view(B, T, self.n_bas, self.bas_dim).transpose(1, 2)
        k = self.K(x).view(B, T, self.n_bas, self.bas_dim).transpose(1, 2)
        v = self.V(x).view(B, T, self.n_bas, self.bas_dim).transpose(1, 2)

        skor = q @ k.transpose(-2, -1) / self.bas_dim**0.5
        att = torch.softmax(skor, dim=-1)
        out = att @ v   # (B, n_bas, T, bas_dim)

        out = out.transpose(1, 2).contiguous().view(B, T, C)  # Başları birleştir
        return self.proj(out)
