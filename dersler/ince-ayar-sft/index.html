İnce Ayar ve SFT (Instruction Tuning)

📚 L7 · LLM Serisi⏱ ~40 dakika
Bu derste öğrenecekleriniz: Temel modeli asistana çeviren süreç, talimat veri seti formatları, chat template, loss maskesi ile sadece cevabı öğretmek ve Hugging Face SFTTrainer ile uçtan uca eğitim.

Temel Model Neden Yetmez?

Önceki derste öğrendik: temel model sadece metni sürdürür. Oysa bir asistanın talimatları izlemesi, soruları yanıtlaması ve ne zaman duracağını bilmesi gerekir. Bu davranışı öğreten aşamaya SFT (Supervised Fine-Tuning) denir.

💡 Analoji

Temel model, tıp fakültesini bitirmiş ama hiç hastayla konuşmamış bir doktordur. Kitap bilgisine sahiptir ama "hasta nasıl karşılanır, nasıl açıklama yapılır" bilmez. SFT, doktorun stajyerlik dönemidir: kıdemli doktorların hasta konuşmalarını izleyerek mesleki davranışları öğrenir. Tıp bilgisi zaten var — öğrenilen şey davranış biçimidir.

Talimat Veri Seti: Modelin Davranış Rehberi

# Standart talimat formatı (JSONL — her satır bir örnek):
{"messages": [
    {"role": "system",    "content": "Sen Türkçe konuşan yardımcı bir asistansın."},
    {"role": "user",      "content": "Bursa'da nereleri gezmeliyim?"},
    {"role": "assistant", "content": "Bursa'da Ulu Cami, Tophane Saat Kulesi ve Cumalıkızık köyünü mutlaka görmelisiniz..."}
]}

# Kalite altın kural: 200 uzman onaylı örnek > 2000 özensiz örnek
# Başarılı SFT için tipik boyutlar: 1.000 - 100.000 örnek

Chat Template: Roller Arası Sınırlar

from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("meta-llama/Meta-Llama-3-8B")

messages = [
    {"role": "user", "content": "Merhaba!"},
    {"role": "assistant", "content": "Merhaba! Nasıl yardımcı olabilirim?"}
]

# Tokenizer, mesajları modele özgü özel token'larla tek metne çevirir:
metin = tokenizer.apply_chat_template(messages, tokenize=False)
print(metin)
# <|begin_of_text|><|start_header_id|>user<|end_header_id|>
# Merhaba!<|eot_id|><|start_header_id|>assistant<|end_header_id|>
# Merhaba! Nasıl yardımcı olabilirim?<|eot_id|>

# <|eot_id|> = End of Turn: model "sıra bitti" işaretini buradan öğrenir.

Loss Maskesi: Sadece Cevabı Öğret

Kritik detay: modelin soruyu değil, sadece cevabı üretmeyi öğrenmesini isteriz. Bunu, kayıp hesaplanırken kullanıcı/sistem tokenlarını maskeleyerek yaparız:

Loss Maskesi — Hangi Token'lardan Öğrenilir?
# Manuel loss maskesi mantığı:
# labels dizisinde maskelenen token'lar -100 olarak işaretlenir
# CrossEntropyLoss -100'ü yok sayar (ignore_index)

etiketler = input_ids.clone()
etiketler[:, :cevap_baslangici] = -100   # Sistem + kullanıcı kısmını maskele
kayip = model(input_ids, labels=etiketler).loss
# Model sadece asistan token'larını tahmin etmekten ceza/ödül alır.

SFTTrainer ile Uçtan Uca Eğitim

from datasets import load_dataset
from trl import SFTTrainer, SFTConfig
from transformers import AutoModelForCausalLM, AutoTokenizer

model_adi = "Qwen/Qwen2.5-1.5B-Instruct"   # Küçük model — Colab ücretsiz GPU'da çalışır
tokenizer = AutoTokenizer.from_pretrained(model_adi)
model = AutoModelForCausalLM.from_pretrained(model_adi, torch_dtype="auto", device_map="auto")

veri = load_dataset("HuggingFaceH4/ultrachat_200k", split="train_sft[:2000]")

ayarlar = SFTConfig(
    output_dir="./cikti",
    num_train_epochs=1,
    per_device_train_batch_size=2,
    learning_rate=2e-5,           # SFT'de LR düşük tutulur — pretraining'den ~10x küçük
    max_length=2048,
    logging_steps=10,
)

egitmen = SFTTrainer(model=model, args=ayarlar, train_dataset=veri)
egitmen.train()
egitmen.save_model("./asistanim")  # Hazır!

Ne Zaman Fine-Tuning, Ne Zaman Prompt?

  • ✅ Fine-tuning gerekli: tutarlı çıktı formatı (JSON şeması), alan jargonu, davranış tutarlılığı, token maliyetini düşürme (kısa prompt yeterli olur).
  • ❌ Fine-tuning gereksiz: bilgi eksikliği (→ RAG kullanın), birkaç örnekle çözülebilen görevler (→ few-shot prompting), genel soru-cevap.
⚠️ Katastrofik Unutma

SFT modelin genel yeteneklerini zayıflatabilir (catastrophic forgetting). Önlem: düşük LR (1e-5 ~ 5e-5), az epoch (1-3), genel veri karışımına biraz genel sohbet verisi eklemek. Değerlendirmeyi unutmayın: hem hedef görevde hem genel benchmarklarda (MMLU gibi) test edin.
