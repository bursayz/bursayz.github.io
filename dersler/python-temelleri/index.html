Python ile Programlama Temelleri

📚 T3 · Temel Serisi ⏱ ~30 dakika
Bu derste öğrenecekleriniz: Değişkenler, veri tipleri, koşullar, döngüler, fonksiyonlar, listeler ve kütüphaneler. Yapay zeka dünyasında her şey Python ile yazılır — bu ders, o dünyaya giriş biletiniz.

Neden Python?

Yapay zeka kütüphanelerinin neredeyse tamamı (PyTorch, TensorFlow, Hugging Face, scikit-learn) Python ile çalışır. Python'un gücü: okunabilirliği ve devasa ekosistemi. Bir satırda yapay zeka modeli eğitmeye başlayabilirsiniz.

💡 ANALOJİ

Programlama dilini bir mutfak dili gibi düşünün. Fransız mutfağı da lezzetli, Türk mutfağı da; ama hangi dilde tarif yazarsanız o dilde çalışan aşçılar size yardım eder. Yapay zeka mutfağında herkes Python konuşuyor.

Değişkenler: Etiketli Kutular

Bir değişken, bir değeri tutan etiketli kutudur. Değeri sonradan değiştirebilirsiniz. 

# Değişken tanımlama
isim = "Zeynep"          # metin (string)
yas = 16               # tam sayı (integer)
boy = 1.68             # ondalıklı sayı (float)
ogrenci_mi = True       # mantıksal (boolean: True/False)

print(isim)             # Zeynep
print(type(yas))        # <class 'int'>

# Değişkenler üzerinde işlemler
gelecek_yil = yas + 1   # 17
print(gelecek_yil)

Koşullar: "Eğer... İse..." Kararları

Koşullar (if/else) programınıza karar verme yeteneği kazandırır: 

not_ = 85

if not_ >= 70:
    print("Geçti! 🎉")
elif not_ >= 50:
    print("Şartlı geçti")
else:
    print("Kaldı 😢")

# Not: girinti (indentation) Python'da ZORUNLUDUR.
# if'in içindeki satırlar sağa kaymış olmalı.
💡 YZ BAĞLANTISI

Bir modelin karar vermesi aslında koşullar zinciridir: "eğer piksel yoğunluğu yüksekse → kenar var"; "eğer kenarlar kapanıyorsa → şekil var"; "eğer şekil kediye benziyorsa → kedi". Milyonlarca minik koşuldan oluşan dev bir karar ağacı.

Döngüler: Tekrar Eden İşler

# For döngüsü: listedeki her eleman için çalışır
dersler = ["Matematik", "Python", "NumPy", "PyTorch"]
for ders in dersler:
    print(f"Bugün {ders} çalışıyorum")

# 5 defa tekrarla
for i in range(5):
    print(f"Adım {i}")  # 0, 1, 2, 3, 4

# While döngüsü: koşul doğru oldukça çalışır
sayac = 0
while sayac < 3:
    print("Çalışıyorum...")
    sayac += 1  # sayac = sayac + 1

Fonksiyonlar: Yeniden Kullanılabilir Araçlar

Fonksiyon, bir işi tanımlayıp tekrar tekrar çağırabileceğiniz araçtır. Bir kez yazıp her yerde kullanırsınız. 

def kare_al(x):
    """Verilen sayının karesini döndürür."""
    return x * x

def tahmin_yap(resim_pikselleri):
    """Basit bir 'model' fonksiyonu — aslında bu, LLM'lerin içindeki dev fonksiyonun minik halidir."""
    toplam = sum(resim_pikselleri)
    if toplam > 500:
        return "kedi"
    else:
        return "kedi değil"

# Kullanım
print(kare_al(5))                      # 25
print(tahmin_yap([100, 200, 300]))     # kedi
print(tahmin_yap([10, 20]))            # kedi değil

Listeler ve Sözlükler

# Liste: sıralı öğeler
puanlar = [85, 92, 78, 95, 88]
print(puanlar[0])        # 85 (ilk öğe, indeks 0'dan başlar!)
print(puanlar[-1])       # 88 (son öğe)
print(len(puanlar))      # 5
print(sum(puanlar) / len(puanlar))  # Ortalama: 87.6

# Listeye ekleme
puanlar.append(91)

# Dilimleme (slicing)
print(puanlar[1:3])      # [92, 78]

# Sözlük: anahtar-değer çiftleri (JSON'un temeli!)
ogrenci = {
    "isim": "Zeynep",
    "yas": 16,
    "notlar": [85, 92]
}
print(ogrenci["isim"])   # Zeynep — anahtarla erişim

# LLM derslerinde API yanıtları hep bu formattadır!
# {"messages": [{"role": "user", "content": "Merhaba"}]}

Kütüphaneler: Başkalarının Yazdığı Süper Güçler

# pip install numpy ile kurulur
import numpy as np

# NumPy'ın gücü: milyonlarca sayıyı saniyede işler
a = np.array([1, 2, 3, 4, 5])
print(a * 2)       # [2 4 6 8 10] — tüm listeyi tek seferde!

# Python listesi ile aynı işi yapmak:
b = [1, 2, 3, 4, 5]
print([x * 2 for x in b])  # Aynı sonuç ama daha yavaş ve uzun
