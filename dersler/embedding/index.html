Embedding: Kelimelerin Koordinatları

📚 L2 · LLM Serisi⏱ ~25 dakika🧊 3D İnteraktif
Bu derste öğrenecekleriniz: Token ID'lerden anlamlı vektörlere geçiş, kelime anlamsal benzerliği, kosinüs benzerliği ve pozisyon encoding. LLM'in kelimeleri nasıl "hissettiğini" görün.

Token ID Yeterli Değil

Önceki derste metni [15234, 8971, 245] gibi sayılara çevirdik. Ama bu sayılar aralarında hiçbir anlamsal ilişki taşımaz: "kedi" ve "kopek" ID'leri arasındaki fark ile "kedi" ve "masa" ID'leri arasındaki fark aynı matematiksel uzaklıktadır. Anlamı temsil etmek için başka bir şey gerekir: embedding.

One-Hot Encoding: İlk Deneme

# Kelime haznesi: ["kedi", "köpek", "masa", "kuş"]
# One-hot: her kelimeye, sadece kendi indeksinde 1 olan bir vektör
kedi  = [1, 0, 0, 0]
kopek = [0, 1, 0, 0]
masa  = [0, 0, 1, 0]
kus   = [0, 0, 0, 1]

# Sorun: "kedi" ile "köpek" ne kadar benzer?
# Dot product: 1*0 + 0*1 + 0*0 + 0*0 = 0
# Hiç benzer değiller mi? Ama ikisi de hayvan!
# One-hot'da TÜM kelimeler birbirine eşit uzaklıkta — anlamsal ilişki yok.

Embedding: Anlamı Sayılarla Kodlamak

Embedding, her kelimeyi yüzlerce boyutlu bir sayı vektörüne dönüştürür ve bu vektörler eğitim sırasında öğrenilir. Benzer bağlamlarda geçen kelimeler benzer vektörlere sahip olur. 

# Embedding matrisi: her satır bir kelimenin vektörü
import torch
import torch.nn as nn

# 1000 kelimelik vocab, 64 boyutlu embedding
embedding = nn.Embedding(
    num_embeddings=1000,   # Kelime haznesi
    embedding_dim=64       # Her kelime kaç boyutta temsil edilecek?
)

token_idler = torch.tensor([15234, 8971, 245])  # Tokenization çıktısı
vektorler = embedding(token_idler)
print(vektorler.shape)   # torch.Size([3, 64]) → 3 token × 64 boyut
💡 Analoji

Dünya haritasında ülkelerin GPS koordinatları var. Ankara ve İstanbul birbirine yakın, Tokyo uzak. Embedding de böyle: "kedi" ve "köpek" kelime uzayında yakın konumda, "kedi" ve "bilgisayar" uzakta. Konum = anlam. Eğitim sırasında benzer bağlamlarda geçen kelimeler birbirine yaklaştırılır.

Kosinüs Benzerliği: İki Vektör Ne Kadar Aynı Yönde?

import torch
import torch.nn.functional as F

kedi_vec  = embedding.weight[10]   # "kedi" embeddingi
kopek_vec = embedding.weight[11]   # "köpek"
masa_vec  = embedding.weight[50]   # "masa"

# Kosinüs benzerliği: -1 (zıt) ile +1 (aynı) arasında
benzerlik_kedi_kopek = F.cosine_similarity(kedi_vec, kopek_vec, dim=0)
benzerlik_kedi_masa  = F.cosine_similarity(kedi_vec, masa_vec, dim=0)

# Eğitimli modelde:
# kedi-köpek: 0.82 (çok benzer)
# kedi-masa:  0.14 (farklı)

Kelime Aritmetiği: Ünlü Örnek

# Embedding'lerde doğrudan vektör aritmetiği yapılabilir:
kral = embedding("kral")
erkek = embedding("erkek")
kadin = embedding("kadın")

# Vektör aritmetiği: kral - erkek + kadın ≈ kraliçe!
sonuc = kral - erkek + kadin

# En yakın kelimeyi bul
tum_embeddingler = embedding.weight  # tüm vocab
benzerlikler = F.cosine_similarity(sonuc.unsqueeze(0), tum_embeddingler)
en_yakin_idx = benzerlikler.argmax()
# → "kraliçe" çıkar (eğitimli modelde)

Pozisyon Encoding: Kelimenin Nerede Olduğu

Transformer mimarisi kelimelerin sırasını doğuştan anlamaz — "kedi köpek" ile "köpek kedi" aynı vektör setini üretir. Sırayı eklemek için pozisyon encoding her tokenın vektörüne eklenir. 

import torch
import torch.nn as nn

kelime_emb = nn.Embedding(1000, 64)    # Anlam vektörü
poz_emb    = nn.Embedding(512, 64)     # Pozisyon vektörü (max 512 token)

x = torch.tensor([42, 17, 99])          # 3 token
pozisyonlar = torch.arange(3)           # [0, 1, 2]

# Anlam + Pozisyon = modelin gördüğü tam temsil
girdi = kelime_emb(x) + poz_emb(pozisyonlar)
print(girdi.shape)  # torch.Size([3, 64])

Embedding Boyutu Ne Kadar Olmalı?

  • GPT-2: 768 boyut | GPT-3: 12.288 boyut | Llama-2 70B: 8.192 boyut
  • Çok küçük boyut → kelimeler yeterince ayrışamaz
  • Çok büyük boyut → daha fazla parametre, daha yavaş, daha fazla veri gerektirir
